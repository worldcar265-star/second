## 워드마크 글리프 시스템

A · Z · A · E 4글자 전부 커스텀 SVG 스트로크 글리프

| 글자 | 구조 |
|------|------|
| A | Λ (람다) 오픈형 — 가로획 없음, 두 사선이 아래로 열림 |
| Z | 위 가로선 + 대각선 + 아래 가로선 |
| A | 첫 번째 A와 동일 |
| E | C-브래킷 (위·세로·아래) + 중간선 별도 |

### 글리프 수치

| 항목 | 수식 | 기본값 |
|------|------|--------|
| Cap Height | fontSize × 0.72 | — |
| Stroke Width | capH × strokeRatio | weight 300 기준 0.048 |
| A box width | fontSize × 0.66 | — |
| Z box width | fontSize × 0.58 | — |
| E 중간선 길이 | 전체 너비의 85% | 0.85 |
| E 중간선 위치 | capH × 0.50 | 세로 중앙 |

### strokeRatio (두께 비율)

| font-weight | strokeRatio |
|-------------|-------------|
| 200 이하 | 0.032 |
| 300 | 0.048 |
| 400 | 0.065 |
| 500 | 0.082 |
| 600 | 0.100 |
| 700 | 0.120 |
| 800+ | 0.155 |

## 글자별 개별 설정

각 글자(A·Z·A·E)마다 독립적으로 조절 가능
- **스타일**: 글리프 / 고딕 / 명조 전환
- **크기**: 0.6× ~ 1.5× 스케일
- **위치**: X/Y 오프셋 (±30px)

## 균열 모드 (Crack Mode)

| 모드 | 효과 |
|------|------|
| none | 정밀 기하학 (기본) |
| subtle | A 꼭짓점 ±1px, Z 대각선 미세 베지어 |
| raw | A 꼭짓점 ±3px, Z 대각선 강한 베지어 |
