# 2026-06-26 — 마카오 컨설팅 + 와사비치킨 소스 R&D + 판단 축 성향

박준호가 페르소나 세션에서 정리한 세 주제 종합. 마카오 메뉴개발 컨설팅 제안 진행 상황 + 와사비치킨 소스 R&D 노트 + 본인의 판단 축 성향 메타 관찰.

## 박준호 자기 진술 (원문 보존)

### 1. 마카오 컨셉 메뉴개발 컨설팅 (올에프엔비 · 서강현 팀장)

- 올에프엔비 글로벌사업팀 서강현 팀장의 마카오 컨셉 신규 브랜드 메뉴개발 컨설팅 — 제안서 발송 후 "보겠다" 회신 받음. 800만원 단일가, "무조건 따내기"가 1순위.
- 서강현 팀장은 오래된 아재꼬막 단골 + 브랜딩 전문가이며, 박준호를 이미 "흥미롭고 좋은 사람"으로 인지하던 관계. 차가운 심사가 아니라 신뢰가 깔린 상태에서 일로 화답하는 구도.
- 제안 프레임: "현지의 맛을 살리되, 한국인에 맞게 변주·디벨롭". 기존 "복제 vs 재설계"에서 단정·평가 말투를 걷어냄.
- 의뢰 범위를 메뉴 개발로 한정. 원가·계절·운영·판매 전략은 의뢰처(올에프엔비) 영역이라 제안서에서 뺌.

### 2. 와사비치킨 소스 R&D

- 토란채(타로) 튀김 식감을 원물 그대로 살리려 했으나 국내 수급이 어려워, 우엉 가라아게 등으로 대체 테스트 중.
- 박준호 판단 — "수주도 안 했는데 결과물(해법)을 미리 보여주는 건 아니다." 해법은 "테스트 중" 신호만 노출, 배합은 미공개(패 유지).
- 구수계는 보유 역량으로 즉시 구현 가능. 소스·비주얼 디벨롭에 집중.

### 3. 컨설팅 800만원 산출 구조

- 대분류: 현지 조사·분석 150 / 메뉴 개발(시그니처·점심·사이드 전체) 500 / 정리·전달·보완 150.
- 개별 메뉴 견적이 아니라 브랜드 메뉴 전체를 통으로 설계.
- 현지 조사·사후 보완까지 800 안에 포함.

### 4. 전달 산출물 (수주 확정 시)

- 메뉴별 레시피
- 소스·시즈닝 배합표(포션 기준)
- 매장 재현용 조립 가이드
- 간 조절은 배합이 아닌 포션으로 — 점포 편차 최소화

### 5. 팝업 게살냉채 관찰 → 지마장 학습

- **팝업 게살냉채 관찰 (박준호 진술)**: 중식 팝업 행사에서 게살냉채를 먹음. 와사비가 들어갔다고 들음. 오이에서 땅콩맛이 났는데 땅콩은 안 들어갔다고 함. 소스는 **이금기 매실 냉채소스**를 썼다고 들었고 성분표에도 땅콩이 없었음. 박준호 의문: **"땅콩이 없는데 어떻게 땅콩맛이 났을까. 와사비치킨도 그랬던 걸까."**
- **(AI 가설 — 박준호 미확정, 사실 아님)**: 그 "땅콩 없는 땅콩맛"의 정체가 혼합 즈마장(참깨+땅콩)일 수 있다는 가능성을 대화 중 검토함. 박준호가 확정한 결론이 아니므로 위키에 사실로 기록하지 않음.
- 지마장·땅콩가루 취급 학습:
  - 기름 분리는 정상(바닥까지 다시 개기)
  - 물 넣으면 처음 뭉치는 "되치기" 현상(따뜻한 액체를 조금씩 한 방향으로)
  - 굳으면 따뜻한 물 중탕
- 재료 역할 분담:
  - 혼합 즈마장 = 소스 바디
  - 볶음 분태 땅콩(지방 있음) = 토핑·식감

### 6. 박준호 판단 (제품화 관점) — 원문 보존

> "유통이 잘 안 되거나 가공이 많이 들어간 특정 상품에 종속되는 건 프랜차이즈 제품화에 안 좋다."

→ 개발·테스트는 완제품으로 빠르게 목표 맛을 잡되, 제품화는 기본 원물(참깨·땅콩)로 역설계해 통제권·마진을 확보.

### 7. 박준호 메타 관찰 — 판단 축 성향 (원문 보존)

> "복제 페르소나로 이야기할 때 관점이 화제 따라 계속 달라진다. 생각 기준과 관점의 일관성을 어떻게 유지할까."

→ 아재꼬막(현재의 현금흐름·신뢰 토대)과 멜트컴퍼니·azae(미래 자산이 쌓이는 축)를 의식적으로 구분. 오늘 대화 내용은 아재꼬막이 아니라 앞으로 만들 사업(멜트컴퍼니 법인) 얘기라고 명시.
