# 위키/지식/ — 박준호가 흡수한 외부 지식

박준호가 R&D·메뉴 개발·컨설팅 등 본인 사업에 도움이 되는 **외부 자료를 학습한 결과·인덱스**를 모으는 자리. [[위키/운영/위키의_본질]] 5원칙에 따라 박준호가 "이건 내가 알아야 할 지식"으로 흡수한 것만 들어옴.

---

## 1. 위키 운영 본질과의 연결

[[위키/운영/위키의_본질]] 4역할 중 본 카테고리의 역할:

- **안다**: 박준호가 흡수한 외부 지식의 위치·범위 알기
- **분석한다**: 박준호 본인 사업·관심과 외부 지식의 연결점 비춰주기
- **기억한다**: 박준호가 어떤 자료에서 무엇을 학습했는지 누적
- **정리한다**: 외부 자료가 누적될수록 박준호의 전문성 지도가 됨

→ 박준호 자기 진술 "음식 분야 가리지 않고 다양 학습 + 식품과학 공부" ([[위키/자아/자기상_자기묘사]] 6.55절)의 외부 자기.

## 2. 운영 원칙 — 저작권 안전 + 박준호 활용성

### 원칙 1: 외부 자료의 본문은 위키에 옮기지 않음
- 책·논문·강의 자료 등 저작권 보호 자료의 본문은 `원본/외부/`에만 보관
- 위키엔 박준호 본인이 만든 콘텐츠만 (인덱스·박준호 관심 매핑·박준호 학습 노트)

### 원칙 2: 위키엔 박준호 본인의 학습 결과
- 인덱스 페이지 = 자료가 어디 있고 무엇이 들어있는지의 박준호 지도
- 활용 노트 페이지 = 박준호가 자료에서 학습·실험·적용한 결과 (박준호 창작 = 저작권 안전, 사업 자산)

### 원칙 3: 빠른 검색은 캐시로 (본인 기기만)
- 외부 자료의 텍스트 추출본은 `.recipe_search_cache/` 같은 폴더에 (`.gitignore` 처리)
- 본인 기기에서 grep·검색 가능, 다른 기기에서는 첫 사용 시 자동 재추출
- GitHub에 안 올라감 → 저작권 안전

### 원칙 4: 박준호와의 연결을 매핑
- 외부 지식 그대로 옮기지 않음. **박준호 사업 라인·관심과의 매핑**을 명시.
- 예: "장사의 정석 1000개 레시피" 중 박준호 양념장 R&D에 활용 가능한 영역, 한식주점 메뉴 후보 영역 등

## 3. 카테고리 구조 (자라남)

```

├── _안내.md (이 파일)
├── 요리·레시피/          (현재 시작)
├── 식품과학/             (식품가공기능사·기술사 학습 시 신설)
├── 소스·양념장/          (소스웍스 협업 R&D 자료 누적 시 신설)

```

새 하위 카테고리는 자료가 누적되며 자라남 — 처음부터 다 만들지 않음.

## 4. 한 자료당 표준 두 페이지

각 외부 자료(책·논문·강의 등)는 다음 두 페이지를 가질 수 있음:

### A. 인덱스 페이지 (필수)
- 자료 정보 (제목·발간·구매·페이지수·PDF 위치)
- 박준호 활용 의도
- 박준호 관심 분야 매핑 (어떤 사업 라인에 어떻게 활용 가능한지)
- 검색하는 법

### B. 활용 노트 페이지 (선택 — 사용하면서 누적)
- 박준호가 그 자료에서 학습한 통찰
- 박준호가 본인 사업·R&D에 적용한 실험·결정·결과
- 시간순 또는 주제순 누적
