# 박준호 R&D 적용 노트 (요리·레시피)

박준호가 외부 자료(예: [[위키/지식/요리·레시피/장사의정석_업소용레시피1000]])에서 학습한 레시피·기법을 본인 사업 R&D에 적용한 결과·실험·결정의 시간 누적 페이지. 박준호 본인이 만든 콘텐츠라 저작권 안전, 박준호 사업 자산.

---

## 1. 이 페이지의 사용법

박준호가 외부 자료의 레시피를 본인 R&D·메뉴 개발에 적용했을 때, 다음 정보를 추가:

- **일자**: 적용 시점
- **참고 출처**: 어떤 자료의 어떤 레시피인지 (페이지 번호)
- **박준호 적용 의도**: 왜 이 레시피를 가져왔는지
- **박준호 변형·조정**: 원본에서 어떻게 바꿨는지 (재료·비율·공정·온도 등)
- **결과·통찰**: 실험 결과, 다음에 어떻게 할지

→ 박준호 본인의 실험 기록이지, 외부 자료 본문이 아님. 저작권 안전.

## 3. 입력 템플릿

박준호가 새 적용을 기록할 때 다음 형식 사용:

```markdown
### [YYYY-MM-DD] [사업 라인] — [레시피 제목 / 적용 주제]

**참고 출처**: [[원본/외부/자료명]] p.XXX — "원본 레시피 제목"

**박준호 적용 의도**:
- (왜 이 레시피를 참고했는지)

**박준호 변형·조정**:
| 항목 | 원본 | 박준호 적용 |
|---|---|---|
| (재료/비율/공정/온도 등) | (원본 값) | (박준호 값) |

**결과·통찰**:
- (실험 결과)
- (다음 적용 시 변경할 점)

**연결**: [[위키/주제/...]]
```
