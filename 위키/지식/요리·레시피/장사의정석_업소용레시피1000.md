## 2. 박준호 활용 의도

박준호가 다운로드한 이유 (2026-05-20 진술 요약):

> "메뉴개발이나 다른 비즈니스 혹은 내 비즈니스에 도움이 될만한 배경지식으로서 내가 어떤 레시피나 고민을 할 때에 참고자료로서 혹은 보다 정확한 데이터로서 추출해서 쓸 수 있으면 좋겠다고 생각해서 다운받아 놨어"

→ 박준호 정체성과 정합: 박준호는 "요리 분야 가리지 않고 다양 학습 + 식품과학 공부" ([[위키/자아/자기상_자기묘사]] 6.55절). 외부 학습 자료를 본인 전문성으로 흡수하는 흐름.

## 3. 책 구조

- **표지·안내**: 1-2 페이지
- **목차 (CONTENTS)**: 3페이지~ (1000개 레시피 제목 + 페이지 번호 나열)
- **본문**: 58페이지~2,819페이지 (한 레시피 당 약 2-3페이지)
- **분류**: 카테고리별 그룹화 없이 단순 1번~1000번 순서 나열 (한식 위주, 일부 일품·반찬·국·찌개·소스·반죽 등)

→ 책 자체에 카테고리 구분이 없으므로, **박준호는 키워드 검색으로 접근**하는 게 가장 효율적.

## 5. 검색하는 법

박준호가 특정 레시피·재료를 찾고 싶을 때:

### 5.1 클로드 챗·Claude Code에 요청

박준호가 다음과 같이 요청하면 자동 처리:

```
"장사의 정석에서 X 레시피 찾아줘"
"장사의 정석에서 재료 Y 들어가는 레시피 모아줘"
"꼬막비빔밥 레시피 어디 페이지에 있어?"
```

→ Claude Code가 `.recipe_search_cache/1000개레시피모음집.txt` 에서 즉석 검색해서 페이지 번호와 함께 알려줌.

### 5.2 직접 검색 (참고용)

박준호가 직접 터미널에서 검색하고 싶으면:

```bash
cd "/Users/junhopark/Documents/Obsidian Vault/second"
grep -n "키워드" .recipe_search_cache/1000개레시피모음집.txt
```

### 5.3 캐시 재생성 (다른 기기에서 처음 사용 시)

다른 기기(맥미니 등)에서 본 vault를 클론했을 때 `.recipe_search_cache/`는 `.gitignore` 처리돼 있어 비어있음. 첫 사용 전 한 번 추출:

```bash
cd "/Users/junhopark/Documents/Obsidian Vault/second"
mkdir -p .recipe_search_cache
pdftotext "원본/외부/1000개레시피모음집.pdf" ".recipe_search_cache/1000개레시피모음집.txt"
```

(2819페이지 추출 약 16초 소요)
