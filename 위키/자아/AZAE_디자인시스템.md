# AZAE 디자인 시스템

박준호가 자기 사업·자기 자신을 외부에 시각적으로 표현하는 시스템. 단순한 색·폰트가 아니라 **박준호의 미감과 한식 본질**을 담은 시각 언어.

---

## 1. 컬러 팔레트 (확정)

| 역할 | 헥스 | 이름 |
|---|---|---|
| Primary | **#8B6F47** | 누룽지 브라운 |
| Accent | **#F5E8D3** | 갓지은 쌀밥 크림 |
| Background | **#FFFBF2** | 따뜻한 화이트 |
| Sub | **#E8D5B8** | 베이지 |

### 컨셉

**한식의 본질 (누룽지 + 쌀밥) + 모던 미니멀**

### 색 이름의 의미

박준호가 색 자체를 한국어로 명명. 헥스 코드보다 **이름이 먼저**. 즉, 박준호의 색은 단순 데이터가 아니라 **이미지·기억·감각**이 먼저.

| 이름 | 환기되는 것 |
|---|---|
| 누룽지 브라운 | 어릴 적 솥밥의 누렇게 탄 바닥, 한국 식문화 가장 깊은 베이스 |
| 갓지은 쌀밥 크림 | 막 지은 흰쌀밥의 부드러운 크림 톤, 일상의 따뜻함 |
| 따뜻한 화이트 | 차가운 회색이 없는 화이트, 인간적 톤 |
| 베이지 | 위 셋을 잇는 중간 톤 |

→ 박준호의 자기 진술 "**좋아하는 색깔: 누룽지 브라운 · 갓지은 쌀밥 크림**" 이 직접 사업 컬러로. **자기 미감 = 사업 디자인**.

## 2. 타이포그래피

| 용도 | 추천 폰트 | 시스템 fallback |
|---|---|---|
| 영문 헤드라인 | Cormorant Garamond / Playfair Display | Georgia |
| 한글 본문 | Pretendard / 본명조 | 맑은 고딕 |
| 코드/모노 | JetBrains Mono | Consolas |

### 페어링 원칙

**영문 세리프 1 + 한글 산세리프 1 조합**. 강의 권장 (최대 2개).

### 박준호식 해석

- **세리프 영문** = 격조·전통·신뢰.
- **산세리프 한글** = 현대성·가독성·일상.
- 둘의 결합 = **"전통의 무게 + 현대의 명료함"**. 박준호의 사업 컨셉 (한식 본질 + AI 시스템) 의 시각 번역.

## 3. 로고

### 현재 버전

- 일러스트 직접 제작 (AZAE 영문 세리프).
- 두 가지 변형: 갈색 배경 (#8B6F47) + 크림 배경 (#FFFBF2).
- 태그라인 (소형): "**손이 기억하는 맛**".

### 로고의 의미

- AZAE 영문 = **"아재" 의 영문 표기**. 친근함을 격조로 전환한 작명.
- 세리프 = 전통주·고급 식품 브랜드 톤. 매타리(@matari.sool) 와 같은 결.
- 두 배경 변형 = 사용 맥락에 따른 페어 시스템.

## 3.5. 워드마크 글리프 시스템 v1.0 (2026-05-05 신설)

박준호가 Illustrator 작업과 병행해 정리한 **로고 구현 스펙**. v0.1 컨셉 단계 → v1.0 실제 구현 가능 단계로 도약. 4글자(A·Z·A·E) 모두 **커스텀 SVG 스트로크 글리프**.

> 원문 보존: [[원본/외부/AZAE_브랜드아이덴티티_2026-05-05]]

### 3.5.1 4 글자의 구조

| 글자 | 구조 | 특징 |
|---|---|---|
| **A** | **Λ (람다) 오픈형** | 가로획 없음, 두 사선이 아래로 열림 |
| **Z** | 위 가로선 + 대각선 + 아래 가로선 | 정통 Z |
| **A** | 첫 A와 동일 | 좌우 대칭 |
| **E** | C-브래킷 (위·세로·아래) + 중간선 별도 | 중간선이 분리된 구조 |

→ **A 의 가로획 없음 + E 의 중간선 분리** 가 박준호 워드마크의 두 시그니처. 일반 알파벳을 그대로 쓰지 않고, **글자를 한 단계 추상화**해 자기만의 형태 언어를 만든 결과.

### 3.5.2 글리프 수치 시스템

| 항목 | 수식 | 기본값 |
|---|---|---|
| Cap Height | `fontSize × 0.72` | — |
| Stroke Width | `capH × strokeRatio` | weight 300 기준 0.048 |
| A box width | `fontSize × 0.66` | — |
| Z box width | `fontSize × 0.58` | A보다 좁음 |
| E 중간선 길이 | 전체 너비의 85% | `0.85` |
| E 중간선 위치 | `capH × 0.50` | 세로 중앙 |

### 3.5.3 strokeRatio (두께 비율) — 굵기 시스템

| font-weight | strokeRatio | 톤 |
|---|---|---|
| 200 이하 | 0.032 | 깃털처럼 가벼움 |
| 300 | 0.048 | **기본값** — 격조 |
| 400 | 0.065 | 정통 |
| 500 | 0.082 | 안정 |
| 600 | 0.100 | 단호 |
| 700 | 0.120 | 무게감 |
| 800+ | 0.155 | 권위 |

→ 박준호의 **기본값 = 300 (0.048)**. 매타리 같은 모던 미니멀 한식 브랜드 톤과 정합.

## 3.7. 글자별 개별 설정 — 변신로봇 디자인

각 글자(A·Z·A·E)는 **독립적으로 조절 가능**:

- **스타일**: 글리프 / 고딕 / 명조 전환
- **크기**: 0.6× ~ 1.5× 스케일
- **위치**: X/Y 오프셋 (±30px)

→ 4 글자가 **하나의 고정 로고가 아니라 변형 가능한 시스템**. 박준호의 [[위키/자아/변신로봇_시스템빌더_징검다리]] 변신로봇 정체성이 로고 시스템에도 적용.

## 3.8. 균열 모드 (Crack Mode) — 가장 흥미로운 발상

박준호가 자기 워드마크에 도입한 **3 단계 정밀도 모드**:

| 모드 | 효과 |
|---|---|
| **none** | 정밀 기하학 (기본) |
| **subtle** | A 꼭짓점 ±1px, Z 대각선 미세 베지어 |
| **raw** | A 꼭짓점 ±3px, Z 대각선 강한 베지어 |

### "균열" 의 함의

- 일반 브랜드 = 한 번 만들면 그대로 고정.
- 박준호 = **정밀 기하학 ↔ 손맛 결의 의도된 진동**.
- "**손이 기억하는 맛**" 태그라인을 로고 형태에도 적용한 것 — 컴퓨터의 정확함 + 손의 미세한 진동.

→ 박준호의 진데리야끼 SOP ([[위키/주제/소스_RnD_진데리야끼]]) 의 정밀 시스템 + 박준호 자기 진술 "**마음 여리고 정 많은**" ([[위키/자아/자기상_자기묘사]]) 의 결합. **시스템 빌더 + INFP Ranger Paradoxitype** 가 디자인에서 만나는 자리.

→ 진데리야끼 SOP 의 "쓴맛 회피" 정밀함과 같은 결인데, 여기서는 **의도된 결함을 디자인 자산으로** 도입한 점이 다름.

## 4. 시그니처 시각 자산

박준호가 정의한 4개 핵심 시각:

1. **꼬막 양념 클로즈업** — 붉은 양념 + 검은 껍질의 컬러 충격. 시그니처 메뉴의 정체성.
2. **손으로 무치는 장면** — "**손맛 · 진정성**". 박준호의 프로 요리사 페르소나 ([[위키/생각/멀티페르소나_운영원칙]]) 가 시각화.
3. **갓 지은 쌀밥 + 꼬막 한 그릇** — 한식의 본질을 한 컷에. 컬러 팔레트의 직접 발현 (누룽지 + 쌀밥).
4. **사장(박준호) 얼굴** — 신뢰·실명 노출. Building in Public ([[위키/주제/SNS_콘텐츠전략_BuildingInPublic]]) 의 인간적 베이스.

→ 4개 시각 자산이 합쳐져 박준호 사업의 비주얼 정체성 형성.

## 5. 디자인 원칙 (박준호 자기 정의)

| # | 원칙 | 함의 |
|---|---|---|
| 1 | **차가운 회색·흰색 톤 금지** | 박준호의 따뜻한 톤과 안 맞음 |
| 2 | **세리프 영문 + 한글 명조 페어링** | 격조 + 가독성 |
| 3 | **여백 우선** | 캔바·인스타 모두 적용 |
| 4 | **꼬막의 컬러는 그대로 살리되, 디자인 톤은 누룽지·쌀밥** | 음식 자체와 브랜드 톤 분리 |

### 원칙 4의 정밀함

- 음식 (꼬막) 의 본래 색 = 붉은 양념 + 검은 껍질 (강한 콘트라스트).
- 브랜드 톤 = 누룽지 + 쌀밥 (부드러운 따뜻함).
- 즉, **음식은 음식대로 강하게**, **브랜드는 브랜드대로 부드럽게**. 두 톤이 충돌하지 않고 보완.

→ 박준호의 [[위키/생각/멀티페르소나_운영원칙]] 의 페르소나 분리 사고가 디자인에도 적용. **음식 페르소나 ≠ 브랜드 페르소나**, 둘 다 박준호의 일부지만 분리해 다룸.

## 6. 박준호의 미감과의 정합

### 6.1 자기 진술

박준호 자기 진술:

> "좋아하는 색깔: **누룽지 브라운 · 갓지은 쌀밥 크림**."

→ 박준호의 개인 미감이 사업 컬러와 100% 일치. 사업이 자기 자신의 외부화.

### 6.2 정서 자아 ([[위키/자아/자기상_자기묘사]]) 와의 정합

박준호의 정서 자아 = "마음 여리고 정 많음". 차가운 회색 톤이 어울리지 않는 이유가 여기에 있음. 디자인 시스템이 정서 자아의 외부 표현.

### 6.3 광주 / 한식 연결

박준호의 정신적 고향 = 광주 ([[위키/장소/광주_정신적고향]]).
누룽지·쌀밥은 한국 식문화의 가장 깊은 베이스. 광주 식문화도 그 베이스 위.
→ 디자인 시스템이 박준호의 지역 정체성과도 연결.

## 13. v2.0 갱신 (2026-05-05) — 브랜드 정신과의 통합

박준호의 AZAE 브랜드 위키 v2.0 ([[원본/외부/AZAE_브랜드정신_v2.0_2026-05-05]]) 입수에 따른 디자인 시스템의 두 번째 도약. 매니페스토는 [[위키/주제/AZAE_브랜드정신_매니페스토]] 참고.

### 13.1 컬러 이름 정밀화 (시적 재명명)

| 역할 | v0.1~v1.0 이름 | v2.0 이름 |
|---|---|---|
| Primary `#8B6F47` | 누룽지 브라운 | 누룽지 브라운 (유지) |
| Accent `#F5E8D3` | 갓지은 쌀밥 크림 | **베이지 크림** (이름 이동) |
| Background `#FFFBF2` | 따뜻한 화이트 | **갓지은 쌀밥크림** (이름 이동) |

→ "갓지은 쌀밥크림" 이라는 가장 시적인 이름이 background 자리로 이동. 박준호 자기 진술:

> "거의 흰색이지만 노란기 0.5%만 살짝 비친 따뜻한 오프화이트. 김이 막 올라온 흰쌀밥의 그 색. 우리 브랜드의 base는 정확히 그 자리에 있다."

### 13.2 워드마크 폰트 변경 — Didone Serif 확정

v1.0 까지: Cormorant Garamond / Playfair Display / Helvetica Neue / Greed.
**v2.0 확정**: **진짜 Didone serif (Bodoni · Didot 계열)**.

#### 박준호의 채택 사상

> "두꺼운 세로/사선 + 가는 가로획의 고대비, 코너의 가는 세리프. Didone 은 18세기 인쇄 장인의 형식미를 대표하는 양식. 손으로 한 글자씩 새기던 시대의 디테일이 그대로 살아있는 글씨."

#### 의미

- **한 끼를 한 사람이 손으로 짓는 행위 + 한 글자를 한 사람이 손으로 깎는 행위** = 두 craft 정신이 한 브랜드 안에서 만남.
- 영문 인쇄 장인 + 한국 인장 장인의 페어링.
- 박준호의 [[위키/생각/짓다_라는_동사]] 사상이 폰트 선택까지 관통.

→ v1.0 의 strokeRatio 7 단계 / 글자별 개별 설정 / 균열 모드는 그대로 유지하되, 베이스 폰트를 Didone 계열로 정렬.

### 13.3 심볼 후보 3 개 — "꼬막인 듯 꼬막 아닌 듯"

박준호 컨셉:

> "심볼이 시각화해야 하는 것은 슬로건의 핵심 동사 **짓다**. 짓는 행위의 흔적, 한 사람이 손으로 만든 것임을 증명하는 mark. origin 스토리(아재꼬막)를 비밀처럼 안에 들고 있으면서 첫 인상은 다른 의미로 읽혀야 함."

#### 후보 1 — 도장 印 / 작가의 인장 ⭐ 메인 후보

- 한국 전통 인장 형식. 작은 원·사각 안에 모티프.
- 작가가 자기가 만든 것에 찍는 가장 본질적 mark — **한 사람이 지었다는 증명**.
- Didone 워드마크의 craft 정신과 가장 강하게 짝.
- 안쪽 모티프로 추상화된 꼬막 골을 두면 *꼬막인 듯 꼬막 아닌 듯* 정확히 작동.
- → 박준호의 [[위키/주제/소스_RnD_진데리야끼]] v3.3 SOP 가 박준호의 craft 증명이라면, 이 인장은 그 craft 의 시각적 도장.

#### 후보 2 — 한 획 + 한 톨

- 미니멀 calligraphy 한 획 + 점 한 톨.
- "한 톨에서 한 끼로" 의 스케일의 시작점.
- 가장 추상적·가장 보편적.
- → 박준호의 [[위키/생각/일_가치관_문제해결_자유]] "작은 문제 → 큰 문제" 사다리 사고와 정합.

#### 후보 3 — 손가락 호

- 손가락이 지나간 자리 같은 단일 곡선.
- 가장 따뜻하고 가장 인간적.
- *손이 기억하는 맛* 과 직결.
- → 박준호의 [[위키/자아/자기상_자기묘사]] 정서 자아 ("마음 여리고 정 많은") 와 가장 가까운 결.

→ 세 후보 모두 origin(꼬막)을 비밀처럼 안고 있되 첫 인상은 다른 의미. 박준호 본인이 추후 선택 / 위키가 추적.

### 13.4 디자인 시스템의 craft 정신

v2.0 에서 박준호가 디자인 시스템 전체를 한 단어로 묶음:

> **craft** — 손·격식·시간이 동시에 들어간 행위. *짓다* 의 영문 등치.

→ 컬러(누룽지·쌀밥의 한국 미감) + 폰트(Didone 인쇄 장인) + 심볼(한국 인장 장인) + 균열 모드(손의 진동) 가 모두 같은 정신. **시스템 빌더 + INFP Ranger** 의 craft 통합.
