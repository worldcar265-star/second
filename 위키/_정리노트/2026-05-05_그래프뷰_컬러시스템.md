# 그래프 뷰 컬러 시스템 — 2026-05-05

## 목적

옵시디언 그래프 뷰에서 위키 카테고리를 한눈에 구분하기 위한 색 매핑. 어디가 빽빽하고 어디가 비었는지 시각적으로 보이게 만든다.

## 컬러 매핑

| 카테고리 | 색 | HEX | 의미 |
|---|---|---|---|
| **자아** | 크림슨 레드 | `#E63946` | 자기 정체성 = 심장·중심 |
| **사람들** | 따뜻한 주황 | `#F4A261` | 관계의 온기 |
| **시기** | 앰버 브라운 | `#A57C50` | 나이테·시간의 결 |
| **장소** | 세이지 그린 | `#588157` | 땅·풍경 |
| **주제** | 딥 블루 | `#1D3557` | 사업·시스템의 구조 |
| **생각** | 머스터드 옐로 | `#E9C46A` | 전구·아이디어 |
| **질문** | 인디고 퍼플 | `#6A4C93` | 미해결·탐구 |
| **_정리노트** | 슬레이트 그레이 | `#8D99AE` | 메타 작업 (중립) |

채도·명도를 비슷한 톤으로 맞춰 그래프에서 한 색이 너무 튀지 않으면서 구분은 또렷하도록 설계.

## 그래프 뷰 적용 절차

1. 그래프 뷰 열기 (`Cmd + G` 또는 왼쪽 사이드바의 동그라미 아이콘).
2. 그래프 뷰 우측 위 톱니바퀴 → **Groups** 섹션 펼치기.
3. **`+ New group`** 으로 그룹 추가, 다음을 채운다:
   - Search query: `path:"위키/<카테고리명>"`
   - 색상 동그라미 클릭 → HEX 입력칸에 위 표의 코드 붙여넣기
4. 8개 그룹 모두 같은 방식으로 추가.

⚠️ **순서 주의**: Groups는 위에서 아래로 적용된다. 좁은 조건(`_정리노트`)이 더 넓은 조건보다 위에 있어야 색이 덮어씌워지지 않는다. 위 표 순서대로 추가하면 자연스럽게 맞다.

## 확장 여지

- 향후 **태그 색상**까지 통일하고 싶다면 `Colored Tags` 플러그인에서 같은 HEX 사용.
- 사이드바 폴더 색까지 통일하고 싶다면 `File Color` 플러그인에서 같은 HEX 사용.
- 추가 카테고리(예: `사건/`)가 생기면 이 표에 한 줄 추가하고 색을 새로 매긴다.
