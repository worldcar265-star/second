# 마카오 메뉴개발 컨설팅 (올에프엔비 · 2026Q2)

**올에프엔비 글로벌사업팀 서강현 팀장**의 마카오 컨셉 신규 브랜드 메뉴개발 컨설팅 수주 건. 박준호 [[위키/주제/azae_컨설팅_사업모델]]의 두 번째 실전 검증 케이스 (첫 번째: [[위키/주제/향미유_RnD_의뢰_2026Q2]] — 늘프레시 향미유, 2026-05-15 보류).

> **⚠ 상태 (2026-07-29):** 본 케이스는 **미회신으로 자연 종료**됨. 박준호 진술: "제안서 넣었지만 연락을 못받고 그렇게 끝난것같아". 완전 종료 확정이 아닌 박준호 판단 상 결렬. 상세는 12절 참고. → 관계기반 영업의 **한계 데이터**로 자산화.

> 박준호 무게 (2026-06-26): "**무조건 따내기**" 1순위. 판단 축 성향(11절)의 "멜트컴퍼니 축 = 미래 자산" 에 속하는 대화. 이 무게는 2026-07-29 시점 결과로 조정됨 (12절).

## 2. 서강현 팀장 관계성 — 관계 기반 영업의 두 번째 사례

박준호의 [[위키/주제/영업_철학_관계기반]] 이 다시 작동한 케이스.

- **오래된 아재꼬막 단골** — 사장·손님 관계 오래 유지
- **브랜딩 전문가** — 서강현 본인의 전문 영역
- **박준호 인지 상태**: 이미 "**흥미롭고 좋은 사람**" 으로 인지된 상태

→ 차가운 심사가 아니라 **신뢰가 깔린 상태에서 일로 화답하는 구도**. 오재석 대표([[위키/사람들/오재석_늘프레시]])의 BNI → 음식 신뢰 → 의뢰 추천 패턴과 결이 같음. 다만 이번은 **손님 관계**가 신뢰 기반.

### 2.1 [[위키/주제/영업_철학_관계기반]] 정합

박준호가 명시적으로 설계한 관계 기반 영업의 두 번째 실증:
- 케이스 1: 오재석 → 향미유 R&D 의뢰 (BNI 모임 신뢰)
- **케이스 2: 서강현 → 마카오 메뉴 컨설팅 (아재꼬막 단골 신뢰)**

두 케이스 공통점: 박준호가 먼저 접근한 게 아니라 **관계자가 박준호에게 일로 화답**.

## 3. 제안 프레임 — "복제 vs 재설계" 걷어냄

박준호의 제안 프레임 확정:

> "**현지의 맛을 살리되, 한국인에 맞게 변주·디벨롭**"

박준호가 초기에 사용하려던 "복제 vs 재설계" 프레임을 걷어냄. 이유: 단정·평가 말투. 의뢰처(올에프엔비)의 선택지를 미리 규정하는 인상이 될 수 있음.

→ 이 조정은 박준호의 [[위키/주제/영업_철학_관계기반]] "가격 경쟁 회피 + 관계성·품질·본질 누적" 결과 정합. 관계 자산은 언어 톤까지 관리.

## 4. 800만원 산출 구조 (박준호 자기 진술)

| 단계 | 금액 | 범위 |
|---|---|---|
| **현지 조사·분석** | 150만원 | 마카오 현지 조사 + 카테고리 분석 |
| **메뉴 개발** | 500만원 | 시그니처·점심·사이드 전체 |
| **정리·전달·보완** | 150만원 | 산출물 정리 + 매장 재현 가이드 + 사후 보완 |
| **합계** | **800만원** | 브랜드 메뉴 전체 통 설계 |

### 4.1 산정 원칙

- **개별 메뉴 견적 아님** — 브랜드 메뉴 전체를 **통으로 설계**하는 견적
- **현지 조사·사후 보완까지 800 안에 포함** — 추가 비용 없음
- → [[위키/주제/azae_컨설팅_사업모델]] 의 유료 착수 프레임 (업계 표준 1종 500만원 / 3종 800만원 — 향미유 케이스)와 다른 접근. 향미유는 SKU 기준, 마카오는 **브랜드 통 견적**.

### 4.2 산정 논리 (박준호 자기 판단)

- 현지 조사·사후 보완을 별도로 뽑지 않고 통에 포함시킴 = **의뢰처에게 예측 가능성 제공** (박준호 [[위키/주제/영업_철학_관계기반]] 결)
- 단, 이 통 견적이 **박준호 시간 대비 적정한지**는 수주 후 실제 시간 트래킹으로 검증 필요 → 보강 권장 (13절)

## 5. 전달 산출물 (수주 확정 시)

박준호가 제안서에 명시한 산출물 3종:

| 산출물 | 형식 | 목적 |
|---|---|---|
| **메뉴별 레시피** | 문서 | 개별 메뉴 재현 |
| **소스·시즈닝 배합표** | 포션 기준 | 배합의 표준화 |
| **매장 재현용 조립 가이드** | 문서 | 매장 편차 최소화 |

### 5.1 박준호의 표준화 원칙 — 배합이 아닌 포션으로 간 조절

박준호 자기 판단:

> **간 조절은 배합이 아닌 포션으로 — 점포 편차 최소화**

→ **왜 이게 중요한가**:
- 배합(레시피)을 매장이 조정하면 → 매장마다 맛 편차 발생
- 대신 **포션(양)만 조정** → 배합은 고정, 편차 통제 가능

→ 이 원칙은 박준호 [[위키/주제/양념장_가게수작업_SOP_Rev1.0]] SOP 마스터의 확장. SOP 설계 원칙의 **프랜차이즈 스케일 적용**.

## 7. 판단 축 성향에서의 위치 (2026-06-26 박준호 자기 진술)

박준호가 오늘 대화에서 명시적으로 자기 판단 축 분리:

> "오늘 대화 내용은 **아재꼬막이 아니라 앞으로 만들 사업(멜트컴퍼니 법인) 얘기**라고 명시."

→ 본 마카오 컨설팅 케이스는 **[[위키/주제/멜트컴퍼니_법인_운영]] 축**에 속함. 아재꼬막(현재 현금흐름) ↔ 멜트/azae(미래 자산 축적) 두 축 중 후자.

### 7.1 시간적 정합 — 2026-06-26 활성 → 2026-06-29 톤다운 대상 아님 → 2026-07-29 미회신 종료 (2026-07-29 재해석)

박준호의 시간 흐름은 다음과 같이 정리됨:

| 시점 | 마카오 컨설팅 상태 | 다른 멜트/azae 축 |
|---|---|---|
| 2026-06-26 | "무조건 따내기 1순위" 활성 | 판단 축 성향 신설 |
| 2026-06-29 | 톤다운 대상 아님 (유지) | 알파랩·신규매장·멜트 법인 톤다운 |
| **2026-07-29** | **미회신으로 자연 종료 (박준호 판단)** | **양념장 B2B 보류 + 무명감자 채널 시작** |

→ 재해석: 2026-06-29 시점의 "톤다운 대상 아님"은 박준호가 마카오를 지킨 것이지만, 실제 결과는 상대(서강현) 측 무회신으로 자연 종료. **박준호가 톤다운하지 않은 항목까지도 외부 신호가 정리해간 흐름**. 즉 2026-06-29 톤다운 흐름의 완성이 2026-07-29의 무명감자 진입점 재편이 되는 이유가 하나 더 확보됨 — **박준호가 지키려 했던 마카오조차도 상대 무응답으로 결렬**되었다는 점.

## 12. 미회신 종료 (2026-07-29 신설)

박준호가 2026-07-28~29 페르소나 대화([[원본/대화/2026-07-28_브랜드우선전략과채널정의]])에서 본 케이스의 상태를 진단.

### 12.1 박준호 자기 진술 (원문)

> "마카오메뉴개발 컨설팅은 제안서 넣어지만 연락을 못받고 그렇게 끝난것같아"

- 상대(서강현 팀장) 측 후속 회신 없음.
- 박준호 진술 어조 = "그렇게 끝난 것 같아" — **완전 종료 선언이 아닌 박준호 판단상 결렬**. 상대의 명시적 거절이 아니라 **무응답에 의한 자연 종료**.
- 재개 여지: 이론상 열려 있으나 박준호의 재접근 의사 없음 (마카오는 [[위키/주제/무명감자_채널]] 우선 순서 아래로 밀림).

### 12.2 이 결과의 관계기반 영업 재검토

6절 수주 확률 판단 근거 4가지는 모두 "강" 또는 "중" 이었음:

| 근거 | 자산 유형 | 6-26 강도 | 실제 결과 |
|---|---|---|---|
| 서강현 팀장 = 아재꼬막 단골 | 관계 자산 | 강 | 무회신 |
| 서강현 = 브랜딩 전문가, 박준호 "흥미롭고 좋은 사람" 인지 | 인지 자산 | 강 | 무회신 |
| 800만원 = 브랜드 통 견적, 예측 가능성 | 견적 구조 자산 | 중 | 무회신 |
| 제안 프레임 톤 조정 | 언어 자산 | 중 | 무회신 |

→ 관계기반 영업의 **4자산이 모두 강했음에도** 결과는 무회신. 이는 [[위키/주제/영업_철학_관계기반]] 의 **한계 조건**을 보여주는 데이터:

- **관계 자산 = 열림 열쇠**이지, 수주의 십분자가 아님.
- **의뢰처 내부 사정**(예산 통과·조직 결정·다른 후보) 은 관계 자산으로 통제 불가.
- **박준호 시선의 "무조건 따내기" 근거**와 **의뢰처 시선의 우선순위**는 다를 수 있음.

→ 이 데이터를 [[위키/주제/영업_철학_관계기반]] 에서 케이스 대비(오재석 수주 vs 서강현 무회신)로 자산화. 관계기반 영업의 **성공 조건 + 한계 조건**을 함께 아는 게 다음 컨설팅 접근에 재사용 가능.

### 12.3 판단 축 흐름의 완성 재해석

7.1절 시간 정합 표에서 본 것처럼, 마카오는 6-29 톤다운 대상이 아니었지만 결과적으로 상대 무응답으로 자연 종료. 즉:

```
2026-06-29 톤다운 흐름 (박준호 능동):
알파랩 · 신규매장 · 멜트 법인 → 톤다운

2026-07-29 무응답 종료 (외부 신호):
마카오 컨설팅 → 무회신 종료 (박준호가 지키려 했음에도)

→ 종합: 멜트/azae 축의 이전 진입점들이 다 좌초
→ 무명감자 채널(개인 브랜드) = 축의 새 진입점
```

→ 본 결과는 [[위키/주제/무명감자_채널]] 6.3절 6월 톤다운 흐름 표 + [[위키/주제/AZAE_브랜드_사업체계]] 16.3절 흐름 표에 반영. 무명감자 진입점 재편의 **필요성 강화 데이터**.

### 12.4 자산으로 남기는 것들

수주는 안 됐지만 다음이 자산으로 남음:

- **800만원 브랜드 통 견적 산출 구조** (4절) — 다음 컨설팅 견적에 재사용.
- **표준화 원칙: 배합 아닌 포션으로 간 조절** (5.1절) — SOP 확장 자산으로 유지.
- **제안 프레임 톤 조정** ("복제 vs 재설계" 걷어냄) — 관계 자산 유지의 언어 원칙으로 재사용.
- **관계기반 영업 한계 데이터** (12.2절) — 위 3자산과 함께 다음 시도에 재활용.
- **와사비치킨 R&D 노트** ([[위키/주제/소스_RnD_와사비치킨]]) — 별도 트랙, 마카오 종료와 무관하게 진행.

### 12.5 향후 재접근 조건 (제안, 박준호 승인 시 채택)

- 서강현 팀장 측 재접근이 있으면 재검토 (박준호가 먼저 재접근하지는 않음).
