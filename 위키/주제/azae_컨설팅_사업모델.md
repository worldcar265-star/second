# azae 컨설팅 사업모델

타당성 상담 → 유료 R&D 착수의 3단계 영업 프레임. AZAE 브랜드 라인 4(컨설팅·SaaS)의 첫 사업 모델.

## 3단계 표준 영업 프로세스

### 1단계: 무료 타당성 상담 (60~90분)

- 의뢰처의 단가·수량·요구사항 듣기
- 현장에서 타당성 시뮬레이션 (Claude 활용)
- "이 조건이면 신규 개발 유리합니다 / 기존 OEM 유지가 낫습니다" 의견
- **시간 제한**: 미팅 2회 안에 결정 못 하면 의뢰처가 진심 아닐 가능성 ↑

### 2단계: 진행 방식 설명·계약

- 타당성 결과 기반 옵션 제시 (A/B/C/D)
- 개발비·기간·진행 단계·결과물 명확화
- 업계 표준 단가: 1종 500만원 / 3종 약 800만원
- 계약 시 50% 선금, 시제품 30%, 양산 결정 20%

### 3단계: 본격 R&D 착수

- 레시피 개발 + OEM 매칭 + QC
- 위탁 생산 또는 직접 도매 납품

## 사업의 본질

박준호는 단순 향미유 OEM 컨설턴트가 아니라 **프랜차이즈 향미 솔루션 시스템 설계자**.

- Layer 1: 컨설팅 (의뢰 케이스)
- Layer 2: 퍼블리싱 (셰프 IP 모델)
- Layer 3: 자체 브랜드 (azae 라인)

## 핵심 자산

- 즉석판매제조가공업 사업자 (시제품 자체 제조 가능) — [[위키/주제/아재꼬막_즉판_운영]]
- 멜트컴퍼니 법인 (유통전문판매업 신고 가능) — [[위키/주제/멜트컴퍼니_법인_운영]]
- 양념장 OEM 경험 (소스웍스, 정풍 등) — [[위키/주제/양념장_B2B_사업]]
- BNI 네트워크 — [[위키/주제/BNI_조찬모임_네트워킹]]
- 한식·일식 R&D 노하우 — [[위키/주제/소스_RnD_진데리야끼]]

## 핵심 원칙

- **레시피·표준화 문서 = IP**로 가치 매김
- 직접 제조 = 시제품·검증·매장 한정
- 양산 = OEM 위탁
- 정보 비대칭 우위 확보 (OEM 공장 정보는 자산)

## 실전 케이스 실증 (2026-07-29 신설)

두 실전 케이스로 본 모델의 성공 조건·한계 조건이 명시화됨.

### 케이스 A — 향미유 R&D 의뢰 (2026-05-14)

- 의뢰처: 늘프레시 (오재석 대표)
- 결과: **수주 성공** → 진행 → 2026-05-15 사업성 부족으로 보류
- 관계 채널: BNI 조찬모임 (음식 신뢰 → 의뢰 추천)
- 검증된 것: **BNI → 음식 신뢰 → 수주** 경로가 작동함.
- 상세: [[위키/주제/향미유_RnD_의뢰_2026Q2]]

### 케이스 B — 마카오 메뉴개발 컨설팅 (2026-06-26 ~ 2026-07-29)

- 의뢰처: 올에프엔비 (서강현 팀장)
- 견적: 800만원 브랜드 통 견적 (본 3단계 표준의 변형 = 개별 견적이 아닌 브랜드 전체 통)
- 결과: **미회신으로 자연 종료**
- 관계 채널: 아재꼬막 단골 (사장·손님 관계)
- 검증된 것: **관계 자산이 강해도 의뢰처 내부 조건(결정권자·예산·우선순위) 통제 불가**.
- 상세: [[위키/주제/마카오_메뉴개발_컨설팅_2026Q2]] 12절

### 두 케이스에서 자산화된 것

| 자산 | 케이스 | 재사용 가능성 |
|---|---|---|
| 3단계 표준 프로세스 (본 페이지) | A | 표준으로 유지 |
| 800만 브랜드 통 견적 산출 구조 | B | 다음 컨설팅에 재사용 |
| 표준화 원칙 "배합 아닌 포션으로 간 조절" | B | SOP 확장으로 유지 ([[위키/주제/양념장_가게수작업_SOP_Rev1.0]]) |
| 관계 기반 영업 성공·한계 조건 매트릭스 | A + B | [[위키/주제/영업_철학_관계기반]] 7절에 종합 |
| 제안 프레임 톤 조정 원칙 | B | 관계 자산 유지 언어 원칙 |

### 다음 컨설팅에서 조정할 관점

- **관계자 = 결정권자인지 먼저 확인**. 팀장급이라도 결재선 확인.
- **의뢰처 내부 예산 통과 시점을 미리 물어보고 견적 시점 맞추기**.
- **관계 기반 영업만으로는 부족** — 개인 브랜드(무명감자, [[위키/주제/무명감자_채널]])가 결정권자에게 도달하는 다음 층을 함께 쌓아야 함.
