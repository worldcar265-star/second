# 무명감자 시그니처 — 인트로/아웃트로 고정 틀

[[위키/주제/무명감자_채널]]의 매 영상에 100% 동일하게 들어가는 고정 틀. 시그니처 자체가 브랜드 각인의 열쇠이기 때문에 **음식·컷·톤이 바뀌어도 이 두 자리는 흔들리지 않는다**. 첫 영상(솥밥/생선)부터 전면 적용.

---

## 1. 인트로 (고정 뼈대 + 교체 슬롯)

### 1.1 문형

> **"왔어요? { 음식 }인데 같이 먹어요."**

박준호 자기 진술 (출처: [[원본/대화/2026-07-28_브랜드우선전략과채널정의]]):

> "왔어요? 솥밥인데 같이 먹어요 라고 했어 음식이 바뀔떄마다 그냥 무슨 솥밥 설명하는거 보다 담백하게 하면 좋을것같아서"

### 1.2 규칙

| 구간 | 상태 | 내용 |
|---|---|---|
| "왔어요?" | 100% 고정 | 반문·환대의 짧은 인사 |
| "{ 음식 }" | 교체 슬롯 | 음식 이름 한 단어만 (짧은 보통명사: 솥밥·전골·국수·구이…) |
| "인데 같이 먹어요." | 100% 고정 | 초대·독백형 |

**절대 금지**:
- 음식 설명 붙이기 ("찰진 솥밥인데…" X)
- 감정 형용사 붙이기 ("따끈한 솥밥인데…" X)
- 관객 부르기 ("여러분 오늘은…" X — 응대 페르소나로 변질)

### 1.3 톤 지시

- **독백 기반** — 손님을 응대하는 것이 아니라 혼자 만들고 혼자 먹으면서 흘리는 말.
- **존댓말이되 살짝 거리 둔 다정함** — 심야식당 주인장의 거리감.
- **담백** — 담백함이 시그니처의 결. 설명·감정 추가하는 순간 다른 채널이 됨.

## 2. 아웃트로 (행위 고정 · 도구 가변)

### 2.1 행위

**다 먹고 도구를 내려놓는 장면 + 소리. 멘트 없음.**

박준호 자기 진술:

> "숟가락이나 젓가락 다 먹는 장면만 들어가긴할거야"

> "끝나는 방식은 숟가락이 될수도 젓가락이 될수도 있고 집게가 될수도있고"

### 2.2 도구는 가변 — 요리 따라

- 솥밥 → 숟가락
- 국수·면 → 젓가락
- 구이·굽는 요리 → 집게
- 나머지 → 요리에 자연스러운 것

→ **도구를 고정하지 않는 이유** = 요리마다 자연스러움을 확보하기 위함. 청각 각인(도구 소리 통일)이 아니라 **시각·리듬 각인(행위 통일)** 을 선택.

### 2.3 각인의 열쇠 = 마지막 컷의 구도·타이밍 고정

동일 프레임 요소 (매 영상 동일):

- 같은 앵글로 **빈 그릇** 잡기
- 같은 자리에 **도구 내려놓기**
- 같은 길이 **페이드아웃**

→ 관객이 도구 소리로 "무명감자 영상 끝"을 인식하는 게 아니라, **"빈 그릇 + 도구 내려놓기 + 페이드아웃"의 리듬**으로 인식하게 만드는 방식.

## 4. 시각 구조 (참고 — 상세는 채널 페이지)

시그니처는 문형·아웃트로만이 아니라 **프로필/썸네일의 반어 구조**까지 포함된 브랜드 자산.

| 자리 | 결 |
|---|---|
| 프로필 | 무명 — 감자 하나 덜렁, 나무 테이블 |
| 썸네일 | 선망하는 모양새 — 잘 차려진 요리 |
| 간극 | "으잉?" — 반어의 잔상 |

→ 상세는 [[위키/주제/무명감자_채널]] 5절.

## 5. 왜 시그니처를 고정하는가

박준호 자기 진술 배경:

> "말을 건내는게 뭔가 이야기를 계속 해야할것같은 느낌이 드는데 혼잣말 형식이면 보다 편안하게 독백처럼 인트로 멘트를 짜면 좋을것같다고 생각이 들었어"

→ **매 영상마다 새 멘트를 짜야 한다는 압박**이 있으면 (i) 채널이 지속 불가능해지고 (ii) 톤이 흔들려서 편안함 결이 무너진다. **틀을 고정**함으로써 두 문제를 동시에 해결.

→ 브랜드 관점에서도, **1편부터 톤이 일관되면 그 자체로 자산**이 된다.
