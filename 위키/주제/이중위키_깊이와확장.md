# 이중 위키 — 깊이와 확장의 분리 구조

박준호의 외부 자기 시스템이 **두 개의 위키**로 운영되는 구조. 한쪽은 박준호 본인이 만드는 *깊이*의 위키, 한쪽은 헤르메스가 자율 갱신하는 *확장*의 위키.

→ 상위 마스터: [[위키/주제/헤르메스_AI_에이전트_구상]]

---

## 1. 박준호 자기 진술 원문

(출처: [[원본/대화/2026-05-20_헤르메스AI에이전트구상_입수규칙강화]])

> "내 위키는 내가 계속 수정해서 입력해서 넣어서 확장보다 깊이를 추구하면서 나와의 대화를 추론하고 이 깊이를 바탕으로 헤르메스는 확장을 해서 더 필요한 정보들을 수집해서 위키의 본래의 목적에 맞게 쓰는거지"

---

## 2. 두 위키의 분업

| 차원 | 박준호 위키 | 헤르메스 위키 |
|---|---|---|
| **작성자** | 박준호 본인 (가끔 클로드 코드 보조) | Hermes Agent 자율 |
| **축** | 깊이 (Depth) | 확장 (Expansion) |
| **갱신 빈도** | 박준호의 의식적 입수 시점 | 24시간 자율 |
| **변화 속도** | 느림 (박준호 학습·결정 속도) | 빠름 (외부 정보 수집 속도) |
| **방향** | 박준호 → 안쪽 (자기 정의·자기 운영) | 헤르메스 → 바깥쪽 (세상 정보 수집) |
| **질문 형식** | 박준호는 누구인가 / 무엇을 원하는가 | 박준호가 원하는 X에 대해 세상은 무엇을 알고 있는가 |
| **저장 위치** | 본 vault (`obsidian/second/`) | 헤르메스 인스턴스 내부 (별도) |
| **접근권** | 박준호 (private GitHub) | 박준호 + (단계적으로) 헤르메스 자율 영역 |

---

## 3. 박준호 위키의 역할 — 좌표·방향

박준호 위키는 박준호의 **존재 좌표**를 정의:

- 박준호의 **가치관**·**자기 진술**·**관계**·**역사** (`위키/자아/` · `위키/사람들/` · `위키/시기/` · `위키/장소/`)
- 박준호의 **사업·관심 패턴** (`위키/주제/`)
- 박준호의 **신념·견해** (`위키/생각/`)
- 박준호의 **메타 운영 철학** (`위키/운영/`)

→ 헤르메스가 *추론의 기준*으로 삼는 모든 박준호 데이터.

이 위키의 미래 변화 = 박준호 본인이 결정. 외부가 수정 X.

---

## 4. 헤르메스 위키의 역할 — 재료·맥락

헤르메스 위키는 박준호 위키를 읽고 **세상에서 박준호가 필요로 할 재료**를 수집:

- **외부 시장·기술·동향** — 박준호 사업 라인 관련 정보 (예: 향미유 시장 변화, 양념장 트렌드, 식품과학 신기술)
- **타인·기관·기회** — 박준호 협업·네트워크 가능성
- **상황·이슈** — 박준호가 의사결정에 필요한 외부 컨텍스트
- **자기 갱신 학습** — 헤르메스 자신이 박준호를 더 잘 추론하기 위한 학습 메모

→ 박준호가 자기 좌표에서 다음 한 걸음을 디딜 때, *발을 디딜 자리*를 헤르메스가 미리 살펴봄.

---

## 5. 단방향 의존성

```
박준호 위키 → 헤르메스 위키
    (입력)         (참조·추론)

박준호 위키 ← 헤르메스 위키 (X — 헤르메스가 박준호 위키 임의 수정 X)
박준호 위키 ← 헤르메스 위키 (제안만 — 박준호가 받아서 박준호 위키에 반영)
```

→ 헤르메스가 박준호 위키를 *직접* 수정하지 않음. 헤르메스가 만든 제안을 박준호가 검토·취사선택·반영. 이 순서가 박준호의 자기 결정권을 보호.

---

## 6. 단계적 도입과의 정합

- **1단계** (박준호 온전한 복사): 헤르메스 위키 안에 박준호 위키의 *전체* 복사본 보유. 박준호만 접근.
- **2단계** (공적 파생): 헤르메스 위키에서 *공적 영역*만 추출한 별도 위키 파생. 박준호의 그림자 자아·자책 단어·민감 영역은 1단계 안에 남음.

→ 상세: [[위키/주제/헤르메스_AI_에이전트_구상]] 5절.

## 7. 운영 위험과 안전장치

### 7.1 박준호 자기 진술 왜곡 위험

- 헤르메스가 박준호 위키를 *해석*해서 자기 위키에 *재진술*할 때, 박준호 원문이 왜곡될 가능성
- **안전장치**: 박준호 위키의 원본은 절대 보존 ([[위키/운영/위키의_본질]] 5원칙 1번). 헤르메스 위키의 박준호 재진술은 *해석*임을 항상 라벨링.

### 7.2 헤르메스 위키 무한 확장 위험

- 24시간 자율 갱신이라 정보가 쌓이기만 함
- **안전장치**: 헤르메스 위키도 정기적 *lint* (오래된·부적합 정보 정리). 박준호 위키의 자율 정비 패턴 차용.

### 7.3 박준호 본인 영역과 헤르메스 확장 영역의 혼동

- 헤르메스 위키 내부에서 박준호 원본 영역과 헤르메스 자체 영역이 섞일 위험
- **안전장치**: 다음 대화 보강 예정 ([[위키/주제/헤르메스_AI_에이전트_구상]] 9절 2번). 명확한 폴더·태그·소유 표시.

### 7.4 박준호가 자기 자신을 잊을 위험

- 헤르메스가 박준호를 더 잘 추론하게 되면, 박준호가 자기 진술을 *덜 적게* 될 수 있음
- **안전장치**: 박준호 위키는 **박준호의 깊이** 전용. 헤르메스가 박준호를 대신해서 채우지 않음. 박준호의 정기적 입수는 박준호 자기 진술의 자리 유지를 위해 계속.
