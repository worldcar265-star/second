# 에이전트 기반 자문 모델

[[위키/주제/AZAE_브랜드_사업체계]] 사업 페이지의 **미래 구조** 섹션. [[위키/주제/다층_번역가]] 정체성이 시장과 만나는 인터페이스.

박준호 인용: *"차차 위키가 심화되고 에이전트가 구축될수록 이 방향성은 더 고도화되어서 다른사람에게 공유하지 않고 나 혼자만사용하고 이 희소성 가치를 가지고 영업을 한다하면 자문이 꼭 만나서 하지 않아도 에이전트로 대체하거나 메일로 의뢰를 받고 정리해서 더 적은 시간을 직접 찾아뵙고 일하지 않을까 싶어"*

---

## 1. 모델이 우회하는 함정

전통적 컨설팅의 함정:

```
컨설팅 = 시간을 파는 비즈니스 = 컨설턴트 자유와 충돌
```

박준호의 [[위키/생각/일_가치관_문제해결_자유]]는 "자유"를 핵심 가치로 두기 때문에, 시간을 파는 구조로 가면 자기 가치와 충돌. 에이전트 자문 모델은 이 충돌을 우회.

## 2.5 박준호 진술로 정밀화된 3층 조직도 (2026-05-22)

2026-05-21 입수의 보강 권장 2번(다섯 페르소나 외재화)에 대해 박준호가 답하면서 본 자문 모델의 조직도가 더 정밀하게 명시화됨. 2절 이중 에이전트 그림이 박준호 본인(핵)을 포함한 3층 구조로 발전.

### 2.5.1 박준호 진술 (원문)

> 내 위키는 내 뇌를 그대로 복사하는 맥락인거야

> 너가 나처럼사고하고 행동하는거지 이 위키는 나만 사용하고 이 위키를 토대로 에이전트를 만든다면 나를 위한 에이전트 인거지

> 헤르메스는 이 내 뇌를 이식하고 헤르메스가 나와 같이 생각한다는 가정하에 외부에 정보와 일들을 나 대신에 수집하고 나에게 역으로 제안하는 방식으로 에이전트를 사용하게 되는거고

> 어떤 에이전트는 이제 비즈니스적으로 외식업자 혹은 기업과 음식 사이에서 어떤 번역이 필요할때 이제 그쪽으로 들어와서 일차적으로 나를 대신하는 에이전트가 응대를 하고 나에게 이제 보고를 올리는 방식으로 조직도 있게 짜여진 에이전트를 구축하는거지

출처: [[원본/대화/2026-05-22_페르소나외재화_조직도구조]]

### 2.5.2 3층 조직도

```
[층 1] 박준호 + 위키 = 핵 (외재화 아님)
              ↕
[층 2] 헤르메스 (개인용 분신, 박준호 뇌 이식)
       - 외부에서 박준호 대신 정보·일 수집
       - 박준호에게 역으로 제안
              ↕
[층 3] 비즈니스 에이전트 조직 (외부 응대용)
       - 외식업자·기업과 음식 사이 번역 의뢰 1차 응대
       - 박준호에게 보고
       - 조직도 있게 짜여진 구조
              ↕
[외부] 외식업자 · 기업 · 소비자
```

| 층 | 정체성 | 사용 주체 | 작동 방식 |
|---|---|---|---|
| **위키** | 박준호 뇌 복사 | 박준호 본인만 | 박준호처럼 사고·행동하는 토대 |
| **헤르메스** | 박준호 뇌 이식 (분신) | 박준호 본인만 (외부 인터페이스) | 외부 수집 + 박준호 역제안 |
| **비즈니스 에이전트** | 박준호 대리 (1차 응대) | 외부 의뢰자 (외식업자·기업) | 응대 + 박준호에게 보고 |

### 2.5.3 2절 이중 구조와의 정합

2절 그림은 [내부 조직도 + 외부 노출 에이전트] 이중 구조. 2.5절 그림은 거기에 **박준호 본인(핵)을 명시 포함** + **헤르메스의 위치를 "외부 수집 + 박준호 역제안" 으로 구체화** + **비즈니스 에이전트를 "조직도 있게 짜여진" 구조로 발전**. 두 그림은 충돌 아닌 정밀화.

### 2.5.4 본 모델의 직접 사례 — 2026-05-22 양념장 OEM

박준호가 [[위키/주제/양념장_OEM_2차_관능테스트_설계]] 에서 AI 1순위 권고(물엿 감량) 를 본질 기준(무침양념장 윤기·물성) 으로 뒤집은 사례 = **층 1(박준호+위키) 이 외부 AI 응답을 본질 패로 응수하는 작동 방식의 첫 실증**. 자문 모델의 핵 보호가 실제로 어떻게 작동하는지 보여준 사례.

→ 즉 이 모델의 작동 전제는 위키·에이전트의 비공개성. 공유되면 희소성 소멸.

## 4. 작동 시나리오

```
1. 클라이언트가 외부 노출 에이전트에 의뢰 (이메일/채널)
2. 에이전트가 의뢰 정리·1차 분석
3. 박준호 내부 조직도(위키+헤르메스+분석 에이전트)와 협업해 답안 생성
4. 박준호가 최종 검토·승인
5. 응답 전달
6. 필요 시에만 박준호 직접 면담 (시간 최소화)
```

전통 컨설팅 대비 박준호 시간 사용량: **수십 분의 1**.
