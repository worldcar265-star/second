# 에이전트 기반 자문 모델

[[위키/주제/AZAE_브랜드_사업체계]] 사업 페이지의 **미래 구조** 섹션. [[위키/주제/다층_번역가]] 정체성이 시장과 만나는 인터페이스.

박준호 인용: *"차차 위키가 심화되고 에이전트가 구축될수록 이 방향성은 더 고도화되어서 다른사람에게 공유하지 않고 나 혼자만사용하고 이 희소성 가치를 가지고 영업을 한다하면 자문이 꼭 만나서 하지 않아도 에이전트로 대체하거나 메일로 의뢰를 받고 정리해서 더 적은 시간을 직접 찾아뵙고 일하지 않을까 싶어"*

---

## 1. 모델이 우회하는 함정

전통적 컨설팅의 함정:

```
컨설팅 = 시간을 파는 비즈니스 = 컨설턴트 자유와 충돌
```

박준호의 [[위키/생각/일_가치관_문제해결_자유]]는 "자유"를 핵심 가치로 두기 때문에, 시간을 파는 구조로 가면 자기 가치와 충돌. 에이전트 자문 모델은 이 충돌을 우회.

---

## 2. 이중 에이전트 구조

```
┌─────────────────────────────────────────────┐
│  [내부 에이전트 조직도 — 비공개]                │
│                                              │
│   ┌───────────┐  ┌────────────┐            │
│   │ 위키기반   │  │ 헤르메스   │            │
│   │ 지식      │  │ 외부지식   │            │
│   │ 에이전트  │  │ 확장       │            │
│   └─────┬─────┘  └─────┬──────┘            │
│         │              │                    │
│         └──────┬───────┘                   │
│                ↓                            │
│   ┌────────────────────────────┐           │
│   │  분석·기획·문서 자동 처리   │           │
│   │  (박준호 직접 고도화)        │           │
│   └─────────────┬──────────────┘           │
│                 │                           │
│   ┌─────────────▼──────────────┐           │
│   │  [외부 노출 에이전트]        │ ←─ 클라이언트
│   │  1차 응대·의뢰 정리·소통    │           │
│   │  (조직도의 일원이자 게이트웨이)│          │
│   └────────────────────────────┘           │
└─────────────────────────────────────────────┘
```

박준호 인용: *"내가 고도화 시킨 나의 에이전트 혹은 에이전트 조직도가 있을거고 소비자들에게 노출되는 에이전트가 있을것같아 아마 에이전트 조직도 안에 있는 하나의 에이전트가 되겠지?"*

---

## 3. 핵심 자산 — 공유 불가능한 희소성

| 자산 | 성격 |
|---|---|
| **박준호의 위키** | [[위키/운영/위키의_본질]] 기반, 박준호 뇌의 외화 — 공유 시 가치 소멸 |
| **헤르메스 에이전트** | [[위키/주제/헤르메스_AI_에이전트_구상]] — 외부 지식 확장 |
| **다층 번역 관점** | [[위키/주제/다층_번역가]] — 권혁만 기술사와도 다른 좌표 |
| **매장 운영 + 컨설팅 실증** | [[위키/주제/B2B_케이스_스터디/양식장_대표님_접근_2026]] 등 누적 자산 |

박준호 인용: *"다른사람에게 공유하지 않고 나 혼자만사용하고 이 희소성 가치를 가지고 영업을 한다"*

→ 즉 이 모델의 작동 전제는 위키·에이전트의 비공개성. 공유되면 희소성 소멸.

---

## 4. 작동 시나리오

```
1. 클라이언트가 외부 노출 에이전트에 의뢰 (이메일/채널)
2. 에이전트가 의뢰 정리·1차 분석
3. 박준호 내부 조직도(위키+헤르메스+분석 에이전트)와 협업해 답안 생성
4. 박준호가 최종 검토·승인
5. 응답 전달
6. 필요 시에만 박준호 직접 면담 (시간 최소화)
```

전통 컨설팅 대비 박준호 시간 사용량: **수십 분의 1**.

---

## 5. 미해결

- 외부 노출 에이전트의 페르소나 — azae 브랜드와의 관계는 어떻게 설정할지
- 내부 조직도의 구성 단위 — 위키·헤르메스 외 어떤 에이전트가 더 필요한지
- 박준호 직접 개입 vs 에이전트 처리의 경계선 — 어떤 의뢰는 반드시 박준호 직접 대면이 필요한지
- 다섯 페르소나([[위키/생각/멀티페르소나_운영원칙]])의 에이전트 외재화 가능성 — 시점이 오면 짚을 좌표
