# AZAE 브랜드 정신 — 매니페스토 v2.0

박준호의 AZAE 사업이 v0.1(컨셉) → v1.0(구현 스펙) → **v2.0(브랜드 영혼)** 으로 도약한 자리. 이 페이지는 사업 체계가 아니라 **사업의 뜻** 을 다룬다. [[위키/주제/AZAE_브랜드_사업체계]] 가 "무엇을 파는가"라면 이 페이지는 "왜·어떻게·어떤 인격으로"를 다룬다.

> 원본 보존: [[원본/외부/AZAE_브랜드정신_v2.0_2026-05-05]]
> 슬로건은 **검토 중**. 5 layer 후보 시스템이 정리되어 있고, 박준호와 추후 브레인스토밍에서 최종 결정 예정.

---

## 1. 한 줄 요약 (브랜드 정체)

> **AZAE 는 한 사람의 손에서 지어진 의미 있는 식사를 만든다.**
> 양념꼬막장에서 시작했지만, 양념꼬막장 회사가 아니다.
> "음식을 짓는다"는 행위 안에 삶이 있다고 믿는 음식 브랜드다.

→ 박준호의 사업 정의가 "**외식 사장의 솔루션**" 에서 "**음식을 짓는 자리**" 로 한 단계 추상화. AZAE 의 카테고리가 외식업·식품업이 아니라 **"음식 본연의 의미를 다루는 자리"** 로 재정의됨.

---

## 2. 신조 (Manifesto Core)

박준호가 잡은 매니페스토의 한 줄 (검토 중 후보):

> **의미있는 식사를 짓습니다.**

### 신조 본문 (요약)
> 빠른 음식의 시대, 효율의 시대, 흉내 한식의 시대에 우리는 한 끼를 짓습니다.
>
> "만든다"가 아니라 **짓는다**. 한국말에서 짓다는 밥을, 옷을, 글을, 집을 — 손으로 격식 있게 만드는 일에만 쓰는 동사입니다.
>
> 한 사람이 한 끼에 정성을 담아 짓는 일.
>
> 한 끼는 인생의 한 컷. 그래서 **잘 먹는 일이 곧 잘 사는 일**.

→ 페이지 [[위키/생각/짓다_라는_동사]] 에서 "짓다" 라는 동사의 사상적 무게 별도 정리.

## 3. 거부의 선언 — AZAE 가 안 가는 자리

매니페스토는 **무엇을 하느냐** 만큼 **무엇을 안 하느냐** 의 선언이기도 함.

| 거부 | 짓는 것 |
|---|---|
| 빠른 음식·인스턴트·즉석 | 시간을 들여 짓는 한 끼 |
| 흉내 한식·가짜 손맛 | 한 사람의 손에서 지어진 진짜 |
| 효율로 환원되는 식사 | 의례·하루의 의식으로서의 한 끼 |
| 마케팅 술수·수사적 자랑 | 정성, 그것 하나 |
| 카테고리 좁힘(한식 전문) | 음식 본연의 의미를 다루는 자리 |

### 박준호 정체성과의 정합

| 거부 항목 | 박준호 정체성 |
|---|---|
| 빠른 음식·즉석 | [[위키/주제/소스_RnD_진데리야끼]] v3.3 (1년 다듬은 SOP) — 시간의 결합 |
| 흉내 한식 | [[위키/생각/윤리_마지노선과_타협의정의]] (사업적 타협 절대 안 함) |
| 효율로 환원 | [[위키/생각/일_가치관_문제해결_자유]] (가치 → 돈, 자유) |
| 마케팅 술수 | "거짓말 안 함" + "기만 안 함" 마지노선 |
| 카테고리 좁힘 | "큰 문제 해결" 추구의 자기 일관성 |

→ 거부 5 항목 모두 박준호의 윤리 마지노선·일 가치관과 일치. 매니페스토가 박준호 자기 자신의 외부화.

## 4. 슬로건 후보 시스템 (5 Layer) — **검토 중**

박준호가 정리한 multi-layer 슬로건 시스템. 한 메시지를 자리에 따라 다른 결로 굴리는 구조. **최종 결정은 추후 브레인스토밍에서**.

### Layer 1 — 신조 (Core Affirmation)
> **의미있는 식사를 짓습니다**

3 단어 분해:
- **의미** — 식사를 가치 판단의 대상으로 둠.
- **식사** — "한식"이 아니라 "식사". 카테고리 확장.
- **짓다** — 한국어에서 가장 격식 있는 행위 동사 (밥·옷·글·집). 1인 셰프·장인의 dignity.

### Layer 2 — 시적 메인 (Poetic Tagline)
> **손이 기억하는 맛**

3 동시 작동:
- 정성·노동(손) — 한식의 본질
- 시간·유산(기억) — "아재" 키워드와 맞물림
- 미각·제품(맛) — 직접적 어필

→ 신조가 머리에 박히면, 이 문장은 가슴에 박힘.

### Layer 3 — 캠페인 카피 (Campaign)
> **한 끼를 인생처럼**

한 끼 = 인생의 한 컷. 누구를 위해 차리고, 어떤 재료로, 어떤 시간을 들이고, 어떤 마음으로 먹는가 — 한 끼와 인생의 동일한 4 질문.

### Layer 4 — 카테고리 라벨 (Category Definition)
> **의미있는 한 끼**

명사구만으로 끝나는 카테고리 정의. MUJI 의 "감지 좋은 생활" 자리에 해당.

### Layer 5 — 영문 페어 (Global Tag)
> **WE CRAFT MEANINGFUL MEALS.**

*짓다* 의 영문 등치 = **craft**. make·create 가 평범하다면, craft 는 손과 격식·시간을 함의하는 거의 유일한 영어 단어.

### 슬로건 시스템의 함의
- 박준호는 한 슬로건이 아니라 **자리별로 갈아 쓰는 슬로건 세트** 를 운영하려 함.
- 마타리(@matari.sool) 모델 ([[위키/주제/벤치마크_호랑이굴_마타리]]) 의 multi-IP 운영과 같은 결.
- 박준호의 [[위키/생각/멀티페르소나_운영원칙]] 변신로봇 정체성이 슬로건 시스템에도 적용.

→ **다음 작업**: 박준호와 함께 5 layer 의 각 후보를 검토·교정·확정. 다른 후보안과 비교.

## 5. 브랜드 스토리

### 5.1 이름의 두 정체성 — 아재 / AZAE

| 면 | 의미 |
|---|---|
| **아재** (한국어) | 친근한 어른·아저씨. 정성껏 차린 음식을 받쳐 드는 인격. 정성·전통·뿌리. |
| **AZAE** (로마자) | 글로벌 어감. 현대·미니멀·확장 가능. |

→ 한 단어 안에 한국 전통의 우직함 + 글로벌 무대의 격조가 공존. 박준호의 [[위키/자아/변신로봇_시스템빌더_징검다리]] 변신로봇 정체성의 브랜드 표현.

### 5.2 출발 — 양념꼬막장 (아재꼬막)

- 박준호 대표의 매장 [[위키/주제/아재꼬막_가게]] 가 모체.
- 꼬막 = 한국 갯벌 식재. 한 톨씩 손으로 까서 양념하는 노동집약적 음식.
- → "**한 톨, 한 톨, 손으로 짓는다**" 는 행위 자체가 브랜드의 metaphor.

### 5.3 한식 → 음식 — 카테고리의 확장

박준호 자기 진술:
> "음식을 먹는 행위는 곧 삶이다. 그렇다면 우리가 다루는 자리는 '한식'이 아니라 '음식'이어야 한다."

→ 이건 사업의 그릇을 더 크게 짓겠다는 선언.
→ AZAE 위키 v0.1 ([[위키/주제/AZAE_브랜드_사업체계]]) 에서 "한식 시그니처" 였던 정의가 v2.0 에서 "**음식 본연의 의미**" 로 확장됨. 박준호의 사다리 사고 ([[위키/생각/일_가치관_문제해결_자유]]) "**작은 문제 → 큰 문제**" 의 사업 표현.

## 6. 비주얼 철학 — 디자인 시스템과의 통합

이 매니페스토에서 새로 도입된 시각 결정들 (디자인 시스템 페이지에 이관 → [[위키/자아/AZAE_디자인시스템]]):

### 6.1 컬러 이름 정밀화
- **갓지은 쌀밥크림** (Background `#FFFBF2`) — v0.1 의 "따뜻한 화이트" 가 더 시적인 이름으로.
- **베이지 크림** (Accent `#F5E8D3`) — v0.1 의 "갓지은 쌀밥 크림" 이 이 자리로 이동.
- → 컬러 3 종 모두 한국 식탁의 본질적 풍경(누룽지 솥 + 흰밥 + 곁반찬) 으로 재정렬.

### 6.2 타이포그래피 — Didone Serif 채택 (v1.0 변경)
- v1.0 에서는 Cormorant Garamond 등.
- v2.0 에서 **진짜 Didone serif (Bodoni·Didot 계열)** 로 확정.
- 이유: 18세기 인쇄 장인의 형식미. 한 글자를 손으로 깎는 craft 정신이 박준호의 "**한 끼를 손으로 짓는**" 정신과 동일.

### 6.3 심볼 후보 3 개 — 박준호 컨셉 "꼬막인 듯 꼬막 아닌 듯"
1. **도장 印 / 작가의 인장** ⭐ 메인 후보 — Didone craft 정신과 가장 강한 페어.
2. **한 획 + 한 톨** — 한 톨에서 한 끼로의 스케일.
3. **손가락 호** — 손이 지나간 흔적. *손이 기억하는 맛* 과 직결.

→ 모두 origin(꼬막)을 비밀처럼 안고 있되 첫 인상은 다른 의미. 자세한 시각 사양은 [[위키/자아/AZAE_디자인시스템]].

## 7. 보이스 & 톤

### 7.1 핵심 인격
> **우직한 장인의 어른**

박준호 대표의 1인 셰프 인격을 그대로 브랜드 인격으로. 박준호의 자기 묘사 "마음 여리고 정 많은" + "또라이끼" + "도전" 의 결합 ([[위키/자아/자기상_자기묘사]]) 이 외부 톤으로 번역됨.

### 7.2 5 가지 보이스 원칙
- 시끄럽지 않다.
- 자기 자랑하지 않는다.
- 정성에 대해서는 단호하다.
- 음식·요리·재료에 대해서는 깊고 구체적이다.
- 한국 음식 전통을 존중하지만 갇히지 않는다.

### 7.3 말투 매트릭스

| 자리 | 우리의 말투 | 우리가 쓰지 않는 말투 |
|---|---|---|
| 자기 소개 | "우리는 한 끼를 짓습니다" | "최고의 한식 브랜드" |
| 제품 | "한 톨씩 손으로 까서 양념합니다" | "프리미엄 양념" |
| 가치 어필 | "정성, 그것 하나" | "고객만족 100%" |
| 사과·실수 | "다음에 더 잘 짓겠습니다" | "불편을 드려 죄송합니다" |

### 7.4 톤의 결
**요란하지 않은 declarative**. MUJI · 교토 장인 브랜드의 결. 외치는 슬로건이 아니라 조용히 약속하는 슬로건. 단호하지만 부드럽다.

## 8. 우리가 믿는 것 — 7 줄 (선언적 정리)

박준호 본인이 압축한 매니페스토의 핵심:

> **음식을 먹는 일은 사는 일이다.**
> **잘 먹는다는 건 잘 산다는 거다.**
> **그래서 우리는 한 끼를 인생처럼 짓는다.**
> **만들지 않는다 — 짓는다.**
> **빠르게 하지 않는다 — 시간을 들인다.**
> **흉내 내지 않는다 — 한 사람의 손에서 지어낸다.**
> **정성, 그것 하나로 다 한다.**

## 9. 박준호 자기 정체성과의 통합

이 매니페스토가 박준호 본인의 어떤 페이지와 어떻게 맞물리는지:

| 매니페스토 요소 | 박준호 자기 페이지 |
|---|---|
| "짓다" 동사 | [[위키/생각/짓다_라는_동사]] (사상적 핵) |
| "정성, 그것 하나" | [[위키/생각/윤리_마지노선과_타협의정의]] (사업적 타협 거부) |
| "한 끼를 인생처럼" | [[위키/생각/인생관_시험과_문제해결]] (인생 = 풀어야 할 문제 + 다음 과정) |
| "잘 먹는 일이 잘 사는 일" | [[위키/생각/행복이_고장났다]] ("만끽 = 휴식·행복") |
| 우직한 장인의 어른 | [[위키/자아/자기상_자기묘사]] (마음 여린·또라이끼) + [[위키/자아/MBTI_ENTJ_Crusader]] (Ranger) |
| 카테고리 확장 (한식 → 음식) | [[위키/생각/일_가치관_문제해결_자유]] (큰 문제 사다리) |
| 변신로봇식 슬로건 layer | [[위키/생각/멀티페르소나_운영원칙]] |

→ 매니페스토는 외부용 브랜드 자료지만 **박준호 자기 자신의 거의 정확한 외부화**. 위키와의 정합도 매우 높음.
