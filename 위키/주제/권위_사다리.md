# 권위 사다리 — 자격증 + 학위 + 실증의 3트랙

박준호가 [[위키/주제/다층_번역가]] 진로 정체성을 시장에서 권위 있는 위치로 끌어올리기 위해 설계한 3트랙 구조. **자격증이 대학원보다 우선**이라는 점이 핵심.

박준호 인용: *"식품공학기능사를 따면 그 다음 기사를 따고 기술사 까지 진행시키는게 이제 내 일단 단기 플랜이야 대학원보다 먼저 그게 내가 갈 분야에서 권위를 얻는 행위 일것같아"*

---

## 1. 세 트랙 구조

### 트랙 A — 기술 트랙 (자격증 사다리)

```
[현재] 식품가공기능사 (필기 합격)
   ↓
[단기] 식품가공기능사 (실기 완료) → 식품가공기사
   ↓
[중기] 식품기사
   ↓
[장기] 식품기술사
```

권혁만 기술사가 도달한 종착점 = 식품기술사. 박준호가 권위 좌표를 같은 사다리에 두는 이유.

### 트랙 B — 학위 트랙

```
[현재] 한양사이버대 호텔외식 (4학년 마지막 학기)
   ↓
[중기] 학사 졸업
   ↓
[장기] 식품공학·조리과학·발효 관련 대학원 (석사)
```

박준호 인용: *"대학원은 식품공학과 조리과학 발효 그런데에 관련된 학위를 생각하고 있어"*

### 축 C — 실증 (사다리에 평행한 축)

```
매장 운영 (아재꼬막 등)
   +
컨설팅 성공 사례 (B2B 케이스 스터디)
   ↓
"소비자 심리에 대한건 매장이라던지 컨설팅을 통해 성공사례가 있다면 충분히 설득가능"
```

박준호 인용: *"사실상 그 학위면 소비자 심리에 대한건 내 매장이라던지 컨설팅을 통해 성공사례가 있다면 충분히 설득가능할거라고 봐"*

→ 실증 축은 [[위키/주제/B2B_케이스_스터디/양식장_대표님_접근_2026]] 등으로 누적됨.

---

## 2. 왜 자격증 우선인가

박준호 인용: *"대학교는 이제 졸업을 하고 하루 아침에 기술사가 되고 길이 정해지는게 아니니까 길게보는거지"*

- 학위는 완료까지 시간이 걸리고, 완료 시점에 바로 권위 형성되지 않음
- 자격증은 **단계별로 즉시 권위 형성** — 기능사·기사·기술사 각 단계마다 시장에서 인정
- 매장 운영과 병행 가능 (학위와 달리 풀타임 강요 안 함)

---

## 3. 동시 진행 한계

박준호 인용: *"한번에 나는 3가지 일 이상을 하면 효율이 떨어진다고 생각해"*

→ 현재 진행 슬롯 (최대 3개):
1. 매장 운영
2. 양념장 B2B + 사업 구축
3. 자격증 ↔ 학위 중 하나 (병행 시 주의)

위키·에이전트 구축은 보조 인프라로 위 3개 안에 흡수.
