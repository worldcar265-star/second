# 권위 사다리 — 자격증 + 학위 + 실증의 3트랙

박준호가 [[위키/주제/다층_번역가]] 진로 정체성을 시장에서 권위 있는 위치로 끌어올리기 위해 설계한 3트랙 구조. **자격증이 대학원보다 우선**이라는 점이 핵심.

박준호 인용: *"식품공학기능사를 따면 그 다음 기사를 따고 기술사 까지 진행시키는게 이제 내 일단 단기 플랜이야 대학원보다 먼저 그게 내가 갈 분야에서 권위를 얻는 행위 일것같아"*

---

## 1. 세 트랙 구조

### 트랙 A — 기술 트랙 (자격증 사다리)

```
[현재] 식품가공기능사 (필기 합격)
   ↓
[단기] 식품가공기능사 (실기 완료) → 식품가공기사
   ↓
[중기] 식품기사
   ↓
[장기] 식품기술사
```

권혁만 기술사가 도달한 종착점 = 식품기술사. 박준호가 권위 좌표를 같은 사다리에 두는 이유.

### 트랙 B — 학위 트랙

```
[현재] 한양사이버대 호텔외식 (4학년 마지막 학기)
   ↓
[중기] 학사 졸업
   ↓
[장기] 식품공학·조리과학·발효 관련 대학원 (석사)
```

박준호 인용: *"대학원은 식품공학과 조리과학 발효 그런데에 관련된 학위를 생각하고 있어"*

### 축 C — 실증 (사다리에 평행한 축)

```
매장 운영 (아재꼬막 등)
   +
컨설팅 성공 사례 (B2B 케이스 스터디)
   ↓
"소비자 심리에 대한건 매장이라던지 컨설팅을 통해 성공사례가 있다면 충분히 설득가능"
```

박준호 인용: *"사실상 그 학위면 소비자 심리에 대한건 내 매장이라던지 컨설팅을 통해 성공사례가 있다면 충분히 설득가능할거라고 봐"*

→ 실증 축은 [[위키/주제/B2B_케이스_스터디/양식장_대표님_접근_2026]] 등으로 누적됨.

---

## 2. 왜 자격증 우선인가

박준호 인용: *"대학교는 이제 졸업을 하고 하루 아침에 기술사가 되고 길이 정해지는게 아니니까 길게보는거지"*

- 학위는 완료까지 시간이 걸리고, 완료 시점에 바로 권위 형성되지 않음
- 자격증은 **단계별로 즉시 권위 형성** — 기능사·기사·기술사 각 단계마다 시장에서 인정
- 매장 운영과 병행 가능 (학위와 달리 풀타임 강요 안 함)

---

## 3. 동시 진행 한계

박준호 인용: *"한번에 나는 3가지 일 이상을 하면 효율이 떨어진다고 생각해"*

→ 현재 진행 슬롯 (최대 3개):
1. 매장 운영
2. 양념장 B2B + 사업 구축
3. 자격증 ↔ 학위 중 하나 (병행 시 주의)

위키·에이전트 구축은 보조 인프라로 위 3개 안에 흡수.

## 5. 사다리 현실 난이도·시간 감각 (2026-05-22 신설)

2026-05-21 입수의 보강 권장 1번 (권혁만 기술사 구체 시간·단계 → 박준호 사다리에 시간 감각 부여) 처리. WebSearch 결과와 객관 데이터로 사다리 현실감 부여.

### 5.1 권혁만 기술사 공개 정보 — 현 시점 미확보

본 vault 측 WebSearch (2026-05-22) 결과:

- 권혁만 기술사에 대한 일반 공개 정보 (셰프 경력 → 기술사 취득 → 샘표 → 자문) 의 **구체 시간·단계는 미확보**
- 박준호가 "유일한 선구자" 로 인식하는 만큼 일반 검색에 잘 잡히지 않음
- [[위키/AI/Claude_응답_규칙_사실기반]] 규칙 4 (모른다고 솔직하게) 에 따라 미확보 명시

→ 본 절은 잠정. 박준호가 권혁만 강연·유튜브 자료에서 직접 알고 있는 정보 (시간·단계) 를 별도 입수하면 본 페이지 보강 가능.

### 5.2 자격증 트랙 (트랙 A) 현실 합격률 — 객관 데이터

출처: 나무위키 식품기사·식품기술사 페이지, 한국식품기술사협회 공개 자료 (2026-05-22 WebSearch).

| 자격 | 합격률 | 비고 |
|---|---|---|
| 식품가공기능사 | (정보 미확보) | 박준호 필기 합격 |
| 식품산업기사 | 70~80% | 기사 대비 쉬움 |
| 식품기사 | 10% 대 (실기 0.2~10%) | **2020 실기 100% 서술형 도입 후 폭락** (2020 1차 0.45%·2021 1차 0.2%) |
| 식품기술사 | **≈ 4%** | 최고 난도 |

→ 박준호 트랙 A 사다리의 단계마다 합격률이 급격히 떨어짐. 특히 **식품기사 단계가 2020 이후 매우 어려워진 상태**. 박준호 "장기 플랜" 표현의 현실적 무게가 명시됨.

### 5.3 사다리 현실 시간 감각 (잠정 추정)

- 식품기술사 응시 자격 = 보통 실무 경력 4년 이상 필수 (응시 조건 확인 권장)
- 박준호의 [[위키/주제/아재꼬막_가게]] 운영 3년차가 실무 경력으로 인정 가능한지 추가 확인 필요
- 권혁만 기술사의 시간 데이터 미확보로 정확 추정 불가
- 합격률 4% 수준의 자격은 통상 다회 응시 누적이 일반적 (단회 합격 드뭄)

→ 사다리 시간 감각의 정확한 부여는 ① 권혁만 자료 확보 + ② 응시 조건 확인 + ③ 박준호 식품가공기능사 실기 → 식품기사 단계 진입 시점 결정 이후로 보류.

### 5.4 박준호 사다리의 현실 의미 (현 시점 정립)

객관 데이터로 명시할 수 있는 것:

- **식품기술사 도달 = 한국 식품 산업 최고 난도** (합격률 ≈ 4%) → 박준호 "권위 형성" 발언의 현실적 무게
- **2020 이후 식품기사 난도 급상승** → 박준호가 "한번에 3가지 일 이상 효율 떨어진다" 한 진술의 시간 사다리와 정합. 한 번에 가는 게 아니라 단계별 누적이 현실적 유일한 경로
- **권혁만 좌표의 희소성** = 합격률 4% 자격 + 미슐랭 3스타 셰프 경력 결합은 매우 특수. 박준호 "유일한 선구자" 인식의 현실적 근거
- **박준호의 차별화 좌표** = [[위키/주제/다층_번역가]] 의 "반대 방향(과학→요리→매장→소비자 다층)" + 매장 운영 실증 축이 권혁만 좌표와의 차별점. 같은 사다리를 같은 방법으로 오르는 게 아님

### 5.5 시점이 오면 짚을 자리표

- 박준호가 권혁만 강연·유튜브 자료 직접 정리 → 5.1절 보강
- 식품기술사 응시 자격 (실무 경력 인정 범위) 확인 → 5.3절 보강
- 박준호 매장 3년차의 실무 경력 인정 여부 확인 → 학위 트랙·자격증 트랙 시간 정합
