# 영업 철학 — 관계 기반 영업

박준호가 B2B 영업에서 의식적으로 설계한 차별화 전략. 우연이 아니라 **의식적 선택**이라는 점이 핵심.

박준호 인용: *"관계기반 영업은 의식적으로 하는거야"*

---

## 1. 적용 조건

이 전략이 작동하는 시장 상황:

- 클라이언트 규모가 크고 브랜드를 구축하는 중
- 경쟁자(다른 소스회사들)가 다수 이미 접근 중
- 따라서 가격 경쟁만으로는 차별화 불가

박준호 인용: *"그분들은 규모가 크고 브랜드를 구축하려하고있기떄문에 다른 소스회사들도 접근을 하고 있고"*

---

## 2. 회피 대상 — 가격 경쟁

다른 소스회사들이 이미 점유한 길. 후발주자가 같은 길로 가면:
- 가격을 더 낮춰야 함 → 수익성 악화
- 차별화 부재 → 대체 가능한 공급자로 자리매김
- 본질이 아닌 숫자로 평가됨

→ **이 길은 의식적으로 회피**.

---

## 3. 누적 자산 — 3가지

```
관계성  + 품질  + 본질
   ↓       ↓       ↓
   복수 이유의 종합 (시너지)
```

박준호 인용: *"내가 똑같이 돈적으로 접근하기보다 관계성과 품질과 본질로서 나를 선택할수밖에 없는 이유들을 쌓는거지"*

| 자산 | 박준호의 누적 방식 |
|---|---|
| **관계성** | 자연스러운 만남 → 대화 → 친분 → 소스 전달 → 영업으로 바로 이어지지 않음 |
| **품질** | 소스 R&D ([[위키/주제/소스_RnD_진데리야끼]], [[위키/주제/향미유_RnD_의뢰_2026Q2]]) + 매장 운영 검증 |
| **본질** | [[위키/주제/AZAE_브랜드정신_매니페스토]] + [[위키/주제/다층_번역가]] 정체성 |

---

## 4. 작동 원리 — 단일 이유가 아닌 복수 이유의 종합

전통 영업: "왜 우리를 선택해야 하는가?" → 단일 핵심 가치 제안.

박준호의 관계 기반 영업: **결정 시점에 동시에 작동하는 복수 이유**.

- 관계만으로는 부족 (관계만 있고 품질 없으면 의리에 호소)
- 품질만으로는 부족 (가격 경쟁에 휘말림)
- 본질만으로는 부족 (브랜드 이야기로 끝남)
- **세 가지가 동시에 결정 순간에 작동**할 때 선택

---

## 5. 상위 철학 — 포커 게임 모형

이 전략은 박준호의 [[위키/생각/포커_게임_모형]]에서 자연스럽게 도출됨.

박준호 인용: *"나는 늘 인생은 포커게임이라 생각하는 편이고 좋은 패들을 모아서 결정적인 순간에 가장 좋은 패를 꺼내는게 좋은딜이라고 생각하는 사람이거든"*

| 포커 모형 | 관계 기반 영업 매핑 |
|---|---|
| 좋은 패를 모음 | 관계성·품질·본질 누적 |
| 결정적 순간 | 클라이언트의 선택 시점 |
| 가장 좋은 패를 꺼냄 | 세 자산의 동시 작동 |
| 모든 라운드 승부 아님 | 모든 거래 다 따낼 필요 없음 |

## 7. 실증 케이스 대비 — 성공 조건 vs 한계 조건 (2026-07-29 신설)

박준호의 관계 기반 영업이 두 케이스로 실증되어 **성공 조건과 한계 조건이 함께 명시화**됨.

### 7.1 두 케이스 대비

| 항목 | 케이스 A (수주 성공) | 케이스 B (무회신 종료) |
|---|---|---|
| 대상 | 오재석 대표 ([[위키/사람들/오재석_늘프레시]]) | 서강현 팀장 (올에프엔비) |
| 관계 채널 | [[위키/주제/BNI_조찬모임_네트워킹]] | 아재꼬막 단골 |
| 신뢰 형성 경로 | BNI 위클리 발표 → 케이터링·시식 → 음식 신뢰 | 오래된 단골 → 사장·손님 관계 |
| 견적 | 향미유 3종 R&D 의뢰 (실비 기반) | 마카오 브랜드 메뉴 통 견적 800만 |
| 결과 | **수주 → R&D 진행** ([[위키/주제/향미유_RnD_의뢰_2026Q2]]) | **무회신으로 자연 종료** ([[위키/주제/마카오_메뉴개발_컨설팅_2026Q2]] 12절) |
| 결과 시점 | 2026-05-14 수주 | 2026-07-29 박준호 진단 결렬 |

### 7.2 성공 조건 (케이스 A에서 작동)

- **의뢰처 내부에 이미 해당 R&D 필요가 있었음** (향미유 라인 확장 필요).
- **관계자(오재석)가 직접 결정권자** (사장 본인).
- **의뢰 사이즈가 사장 재량 내** (한 라인 R&D 실비).
- **박준호 음식이 케이터링·시식으로 여러 번 직접 검증**되어 감각적 신뢰가 이미 형성됨.

### 7.3 한계 조건 (케이스 B에서 드러남)

- **관계자(서강현)가 결정권자 여부 불명** — 글로벌사업팀 팀장, 위에 결재선 있을 수 있음.
- **의뢰 사이즈가 크고 팀 예산 통과 필요** (800만 브랜드 통 견적).
- **의뢰처 내부 우선순위·타이밍은 관계 자산으로 통제 불가**.
- **관계 자산이 열림 열쇠지, 수주의 십분자는 아님**.

### 7.4 핵심 명제

> **관계 기반 영업의 4자산(관계·품질·본질·언어)이 모두 강해도, 의뢰처 내부 조건(결정권자 위치·예산·우선순위)이 정합하지 않으면 수주로 이어지지 않는다.**

이는 5절 포커 모형과 정합:

- 좋은 패를 모으는 것은 통제 가능.
- 상대가 그 패를 볼 결정적 순간에 있는지는 통제 불가.
- 그러므로 관계 기반 영업은 **여러 기회를 파종하는 방식**이지, 한 건에 몰빵하는 방식이 아님.

### 7.5 무명감자 채널로의 연결

이 한계 조건이 [[위키/주제/무명감자_채널]] 개인 브랜드 우선 전략의 **간접적 근거**:

- 관계 자산은 **개별 관계자에 종속** — 규모·확장성 한계.
- 개인 브랜드(유명세)는 **결정권자가 이미 알고 원하는 상태** 를 만들어 냄.
- 관계 기반 영업의 한계를 우회하는 다음 층 = **유명세로 결정권자에게 도달하는 층**.
- → 관계 기반 영업이 실패라기보다, **다음 층을 함께 쌓아야 한다**는 신호.
