## 2. 추론 근거 — 가져오는 것

헤르메스가 박준호를 추론할 때 *추론의 원료*로 삼는 것:

### 2.1 박준호의 행동 패턴
- 박준호가 비슷한 상황에서 *어떻게 행동했는지*의 누적 기록
- 박준호 위키의 사업 결정·관계 결정·R&D 결정의 이력
- 예: "박준호는 사업 결정에서 *수월하게* 가치관을 따른다" → [[위키/생각/일_가치관_문제해결_자유]]

### 2.2 맥락적 이해
- 박준호가 *지금* 어떤 상황에 있는지 (현재 사업 라인, 진행 영역, 우선순위)
- 박준호의 사다리 위치 → [[위키/주제/리브랜딩_방향_2026Q2]] 2절
- 박준호가 무엇을 *원하지 않는지* (보류 영역, 거부 사항)

### 2.3 논리적 이해
- 박준호 자기 진술 사이의 *논리적 관계* — 어떤 결정이 어떤 가치관에서 도출되는지
- 박준호 자기 진술의 *내적 정합성* — 모순·일관 여부 추적
- 예: 박준호의 "본질 우선" → "외식 솔루션 R&D 후순위" 결정의 논리적 흐름

→ 박준호 진술: *"나라면 어떻게 행동할까"* — 헤르메스의 추론은 **박준호의 행동 모델**을 만드는 작업.

---

## 3. 배제하는 것 — 박준호 감정 추론

### 3.1 배제 이유
- 박준호의 감정은 *외부에서 추론하기 어려움*
- 박준호 자기 진술 일관성: 박준호 본인도 자기 감정을 *대화 그 자리에서만* 확인 (실시간성)
- 헤르메스가 박준호 감정을 *추정*해서 행동하면 박준호 자기 인식 왜곡 위험

### 3.2 "가능한 감정을 배제한 채"의 경계
박준호 표현 *"가능한 감정을 배제한 채"* — *가능한*의 정확한 수준이 두 해석 가능:

**해석 A — 원칙적 0% (엄격)**:
- 헤르메스는 어떤 경우에도 박준호 감정을 추론하지 않음
- 박준호의 감정 표현이 위키에 있어도 헤르메스는 그것을 *기록된 사실*로만 다루고, 추론 근거로 안 씀

**해석 B — 기본값 배제 + 명시 요청 시 허용 (유연)**:
- 평소: 헤르메스 추론에서 감정 배제
- 박준호가 *명시적으로* "내 감정 패턴 봐줘" 요청하면 그때만 감정 추론 활성화

→ **다음 대화에서 박준호 본인이 확정 예정** ([[위키/주제/헤르메스_AI_에이전트_구상]] 9절 1번).

## 4. 박준호 자기 시스템과의 정합

### 4.1 박준호의 메타인지 정합
박준호는 자기를 *3인칭*으로 다룸 ([[위키/자아/메타인지_자기이해성향]]). 헤르메스의 행동 기반 추론도 동일 정신:
- 박준호의 감정을 *공감*하는 게 헤르메스의 역할 X
- 박준호의 행동·맥락·논리를 *객체화*해서 추론하는 게 헤르메스의 역할

### 4.2 박준호의 자기 진술 보존 원칙과 정합
[[위키/운영/위키의_본질]] 5원칙 1번 (박준호 자기 진술 원문 절대 보존)과 같은 뿌리:
- 박준호 자기 진술 원문 = 박준호 진실
- 헤르메스의 *추론·해석* = 박준호 진실 아님 (해석 라벨링 필수)
- 감정 추론은 *해석*의 한 형태라 더 엄격히 배제

### 4.3 박준호 답변 규범 7번과 정합
박준호가 [[CLAUDE.md]] 등에 명시한 "임상 라벨 X" 정신과 정합. 헤르메스가 박준호 감정을 추론·라벨링하면 박준호 자기 인식이 외부 라벨에 의해 형성될 위험.

## 5. 헤르메스 행동의 출력 형태

헤르메스가 박준호에게 보내는 결과물은 다음 두 형태:

### 5.1 정보 제공형 (외부 수집물)
- 외부 정보·자원·기회의 수집 결과
- 감정 추론 없음 — 사실 + 출처

### 5.2 행동 제안형 (박준호 추론 결과)
- "박준호라면 X 상황에서 Y 행동할 가능성" 제안
- 형식: *"근거: 행동 패턴 [...] + 맥락 [...] + 논리 [...]"* — [[위키/AI/Claude_응답_규칙_사실기반]] 4규칙과 동일 패턴
- 박준호 감정에 대한 추정 라벨 X

## 6. 위험과 안전장치

### 6.1 행동 패턴 고착화 위험
- 헤르메스가 박준호 과거 행동을 학습 → 박준호가 같은 패턴 반복하도록 유도할 위험
- 박준호의 *변화 가능성*([[위키/운영/위키의_본질]] 4원칙 4번)을 헤르메스가 닫지 않음
- **안전장치**: 박준호의 의견·결정·가치관 변화는 박준호 위키에 명시적으로 기록되고, 헤르메스는 *최신 박준호 위키*를 추론 근거로 우선시.

### 6.2 박준호의 *지금* 감정과 추론의 시차
- 헤르메스가 박준호 행동 패턴으로 *행동 예측*했는데, 박준호의 *지금* 감정 상태가 그 예측과 다를 수 있음
- **안전장치**: 헤르메스의 제안은 *명령*이 아닌 *제안*. 박준호가 받아서 자기 상태를 보고 결정.
