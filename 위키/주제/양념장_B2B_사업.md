# 양념장 B2B 사업 (AZAE 브랜드 — 라인 2)

박준호가 **"투자를 받기 위해 구조를 짜고 법인 전환을 하고 매출을 일으켜야 해서"** 진행 중인 핵심 사업. 2026-05-03 박준호 본인이 작성한 AZAE 위키에 따라 이 사업은 **AZAE 브랜드의 라인 2 (B2B 제조)** 로 명확히 정렬됨.

> **⚠ 상태 (2026-07-29):** 본 사업은 **보류(pause)** 로 전환됨. 접은 것이 아니라 시장 조건과 앵커 이탈에 근거한 절제. 상세는 아래 9절 참고. 6월 톤다운 흐름([[위키/주제/아재꼬막_신규매장_2026]] · [[위키/주제/멜트컴퍼니_법인_운영]] 보류)의 연장선.

## 1. 자기 진술 (원문)

> 투자를 받기 위해 구조를 짜고 법인 전환을 하고 매출을 일으켜야 해서, **양념장을 개발하고 이 양념장을 기반으로 B2B 사업을 진행**하려고 하고 있어. 그 일들이 잘 해결되어야 할 거라는 걱정이 있고.

---

## 2. 사업의 구조 (자기 진술 정리)

박준호가 풀어놓은 한 단락 안에 실은 **세 단계가 묶여있다**:

```
[양념장 개발] → [B2B 사업화] → [매출 발생] → [법인 전환] → [투자 유치]
```

각 단계가 서로 의존:
- **양념장이 있어야** B2B로 팔 수 있음.
- **매출이 있어야** 법인 전환의 의미가 있음.
- **법인이 되어야** 투자를 제대로 받을 수 있음.
- **투자가 들어와야** 다음 사업 (초콜릿/싸는음식/AI 에이전트) 의 운영 자본 확보.

→ 즉, 양념장은 **단순한 한 사업이 아니라 박준호 사업 포트폴리오 전체의 첫 도미노**.

## 2.5 B2B 영업 3채널 (AZAE 라인 3, 2026-05-04 신설)

박준호가 AZAE 위키에서 명시한 영업 채널 3개. 라인 2(제조) 가 만든 제품을 흘려보내는 통로.

### 채널 A — 프랜차이즈 본사 납품

- 대상: 외식 프랜차이즈 본사.
- 상품: 꼬막 소스 + 냉동 꼬막 **묶음**.
- 가치: 본사 입장에서 **신메뉴 개발 비용 절감**.

### 채널 B — 꼬막 공급업체 역납품 (역방향 공급망)

- 대상: 박준호에게 꼬막 원물을 공급하는 업체.
- 상품: AZAE 소스.
- 가치: 공급사가 자기 B2C 채널에서 박준호 소스를 **함께** 판매.
- 박준호 자기 표현: "**본인의 공급사가 본인 제품을 팔아주는 구조**".
- → 매타리(@matari.sool)의 Partners 협업 구조와 닮음 ([[위키/주제/벤치마크_호랑이굴_마타리]]).

### 채널 C — 케이터링 업체 납품

- 대상: 케이터링 회사.
- 가치: 행사 메뉴에 한식 시그니처 추가.

### 핵심 자세 (박준호 한 줄 정의)

> "**나는 B2B를 받지만, 그들은 B2C가 쉬워지는 비즈니스**."

→ 3 채널 모두의 공통 검증 기준. 페이지 [[위키/주제/AZAE_브랜드_사업체계]] 4.x 참고.

## 3. 식품가공기능사 자격증과의 정합성

박준호가 **식품가공기능사 필기 합격, 실기 예정** 인 이유가 여기서 명확해짐:

- 양념장 = 식품가공의 한 영역.
- 식품가공기능사 자격은 양념장 제조의 **현장 자격 / 영업 신고의 근거**.
- → 학과(호텔외식경영) + 자격증(식품가공) + 사업(양념장 B2B)이 한 줄로 정렬.
- 페이지 [[위키/자아/자격증_보유기술]] 의 "트랙 B" 가 이 사업과 직결됨.

## 4. 가게(아재꼬막)와의 관계 — R&D 연결

(추정) 양념장은 **아재꼬막에서 쓰는/개발한 양념장이 모태**일 가능성이 큼:

- 자영업자가 자기 매장에서 검증된 양념장을 상품화하는 것은 외식업의 정석 패턴.
- 아재꼬막 = **시제품 검증 환경**, 양념장 B2B = **사업 확장 단계**.
- → 가게가 무너지면 양념장의 정체성·맛·근거도 흔들림. 가게 운영의 중요도가 두 배.

## 4.5 첫 외부 검증 사건 — BNI 조찬모임 발표 (2026-05-04 신설)

박준호의 4차 인터뷰에서 새로 등장한 사건:

> "매주 화요일 나가는 BNI 조찬모임에서 **저번 주에 소스 샘플을 들고 가서 위클리 발표**를 했더니, **투자 쪽 사람과 정책자금 관련 업계 사람들이 대화하자고** 하는 게 굉장히 흥미로웠고. **그게 미팅으로 이어져서 투자와 법인 전환에 대해 이야기 나누는 것**도 무척이나 즐거웠어."

→ 박준호의 양념장 B2B 사업의 **첫 외부 검증 사건**. 추상적 계획이 아니라 이미 진행 중임을 증명.

### 사건 흐름
```
[양념장 개발] → [BNI 위클리 발표 (샘플 시연)] → [투자·정책자금 업계 관심 발생]
                                                ↓
                          [미팅 성사] → [투자 + 법인 전환 논의]
```

→ 페이지 [[위키/주제/BNI_조찬모임_네트워킹]] 에서 사건 자체의 의미·맥락 정리.

→ 사업 사다리 ([[위키/생각/일_가치관_문제해결_자유]]) 의 다음 칸이 추상에서 구체로 전환된 마일스톤. ENTJ Crusader 의 외부 검증 욕구가 채워지는 자리.

## 4.6 B2B 영업 검증 흐름 — 음식 신뢰 → 의뢰 수주 (2026-05-14 신설)

박준호의 B2B 영업이 **샘플 발표만이 아니라 케이터링·시식 → 음식 신뢰 → 의뢰 수주** 라는 별도 트랙으로도 작동함을 보여주는 사례. 이쪽이 더 깊은 신뢰를 만드는 경로.

### 검증된 패턴
```
[박준호 R&D 자산 (데리야끼 v3.3 등)]
        ↓
[BNI 케이터링·시식 직접 제공]
        ↓
[음식 신뢰 형성 (오재석 대표)]
        ↓
[R&D 의뢰 추천·수주 (향미유 3종)]
```

→ 첫 외부 의뢰 수주 = [[위키/주제/향미유_RnD_의뢰_2026Q2]] (늘프레시 케이스)

### B2B 영업의 두 트랙 비교

| 트랙 | 자산 | 결과 |
|---|---|---|
| **트랙 1 — 샘플 발표** (4.5) | 양념장 샘플 + 위클리 1분 발표 | 투자·정책자금 업계 미팅 |
| **트랙 2 — 케이터링·시식** (4.6) | 케이터링 + 데리야끼 v3.3 시식 | 음식 신뢰 → R&D 의뢰 |

박준호의 양념장 B2B 사업이 **추상적 계획이 아니라 실제 매출·의뢰로 흘러가는 트랙이 확보**된 상태. AZAE 라인 2(제조) 의 다음 단계는 향미유 라인 추가 ([[위키/주제/향미유_RnD_의뢰_2026Q2]]) 와 함께 진행.

## 5. 박준호의 걱정 (자기 진술)

> "그 일들이 **잘 해결되어야 할 거라는 걱정**이 있고."

이 한 줄 안에 박준호의 ENTJ Type Angst의 흔적이 있다.

- 박준호의 그림에서 양념장 B2B는 **반드시 성공해야 다음이 가능**. 따라서 실패의 무게가 큼.
- ENTJ J 의 함정 — "한 번에 안 되면 끝이다" 식의 압박감.
- 자기 점검 신호: 이 걱정이 추진력으로 쓰일 때는 좋은 자극, 자기 의심으로 변하면 [[위키/생각/안풀릴때_대처법_메타인지]] 의 행동 루틴(런닝·노래·관찰)으로 처리.

## 7. 의미 재정의 — 수단 + 첫 컨설팅 케이스 스터디 (2026-05-21)

2026-05-21 [[위키/주제/다층_번역가]] 진로 정체성 정리 과정에서 본 사업의 **이중 의미**가 명시화됨.

### 7.1 양념장 B2B = 수단

[[위키/생각/일_가치관_문제해결_자유]]의 사다리 모형에서 본 사업의 위치는 **중간 칸**:

```
[가장 위 칸] 다층 번역 컨설팅 (큰 문제, [[위키/주제/에이전트_자문_모델]])
   ↑
[중간 칸] 양념장 B2B 사업 ← 본 페이지
   ↑
[아래 칸] 아재꼬막 가게
```

→ 본 사업은 종착점이 아니라 **다음 칸(컨설팅)으로 가는 다리이자 실증 데이터 누적 트랙**.

### 7.2 양념장 B2B = 첫 컨설팅 케이스 스터디

박준호 인용 (출처: [[원본/대화/2026-05-21_진로정의-다층번역가-에이전트자문]]):

> *"앞으로 따로 위키에 컨설팅 케이스 스터디 자료로서 b2b 에 관한 이야기를 할떄 저장할수 있도록 하자... 그런 자연스러운 접근방법도 세세하게 기록해서 나중에 컨설팅 자료로서 쓰면 좋을것같아"*

→ 양식장 대표님 접근 (자연스러운 친분 → 소스 전달 → 영업 절제)이 [[위키/주제/영업_철학_관계기반]]의 **첫 의식적 적용 케이스**. 진행 과정 전체가 향후 컨설팅 자료로 누적됨.

상세 케이스 기록은 [[위키/주제/B2B_케이스_스터디/양식장_대표님_접근_2026]] 분기.

## 8. 꼬막양념장 R&D 자산 — 가게 수작업 SOP + OEM 가열 이슈 (2026-05-22 신설)

2026-05-22 박준호가 꼬막양념장 1차 샘플 배합표(7,047g)와 가게 수작업 공정 + OEM 가열 라인의 결 변성 이슈를 입수. 양념장 B2B 사업의 가장 구체적인 R&D 자산이 두 페이지로 분기되어 정리됨.

### 8.1 가게 수작업 SOP — Rev. 1.0

[[위키/주제/양념장_가게수작업_SOP_Rev1.0]] 에 상세.

핵심:
- 1회 작업 단위 = 7,047g (1차 샘플 기준)
- 기준 원가 = 41,875원 / 7,047g (g당 약 5.94원)
- 공정 = 미림+생야채 5종 믹서 → 나머지 재료와 혼합 → 냉장 1일 숙성
- 원가 동인 1위 = 고춧가루 (국내+중국산 합산 56.8%)

→ [[위키/주제/소스_RnD_진데리야끼]] (v3.3) 와 함께 박준호 **직접 작성 SOP 2종** 라인업 완성. AZAE 라인 2(B2B 제조)의 가장 구체적인 R&D 자산.

### 8.2 OEM 가열 라인 결 변성 이슈

[[위키/주제/양념장_OEM_2차_관능테스트_설계]] 에 상세.

OEM 생산 구조:

| 구분 | 처리 | 유통 | 채널 | 상태 |
|---|---|---|---|---|
| 벌크 포장 | 비가열 급냉 | 냉동유통 | B2B | 완성 |
| 소포장 | 가열 (HACCP 살균) | 상온/냉장 | B2C / BNI 유통업체 | 결 조정 중 |

가열 라인 결 변성:
- 현상 = 첫 단맛 강화 + 감칠맛 극대화 → "오징어볶음 소스처럼"
- 박준호 결정 = 미원↓ + 설탕 10%↓ + 황설탕 대체 라인 (시제품 중) / 수크랄로스 검토 / **물엿 유지** (AI 1순위 권고 뒤집음)

박준호 자기 시스템 작동:
- **포커 게임 모형** ([[위키/생각/포커_게임_모형]]) — 무침양념장 본질(윤기·물성)을 본래 패로 인지, AI 권고에 본질 기준으로 응수
- **에이전트 자문 모델** ([[위키/주제/에이전트_자문_모델]]) — AI 응답을 그대로 받지 않고 본인 판단으로 검증·뒤집기. 자문이 박준호 판단을 **대체하지 않고 보조** 한다는 구조의 실증

### 8.3 사업 구조에서의 위치

본 SOP·OEM 자산은 양념장 B2B 사업의 **3종 검증된 R&D 자산** 의 일부:

1. **꼬막양념장** (본 두 페이지) — 1차 샘플 배합 + OEM 2채널 진행 중
2. **진데리야끼** ([[위키/주제/소스_RnD_진데리야끼]]) — v3.3 완료, 사업화 후보
3. **향미유** ([[위키/주제/향미유_RnD_의뢰_2026Q2]]) — 늘프레시 의뢰, 사업성 부족으로 보류 ([[위키/주제/리브랜딩_방향_2026Q2]])

→ 본 페이지 0절 라인업 표의 1번 (꼬막 소스) 의 **실제 R&D 깊이**가 두 페이지로 분기되어 가시화됨.

## 9. 상태 전환 — 진행에서 보류로 (2026-07-29 신설)

박준호가 2026-07-28~29 페르소나 대화에서 본 사업을 **보류(pause)** 로 명시. 접음(cancel)이 아니라 시장 조건과 앵커 이탈 + 순서 재정렬에 근거한 절제.

### 9.1 사유 3가지

박준호 자기 진술 (출처: [[원본/대화/2026-07-28_브랜드우선전략과채널정의]]):

> "대형 꼬믹 양식장이 소포장 소스를 직접 만들겠다고 했고 oem 도 지금 한국시장이 위축해있는 상태라서 납품처를 확보해놓지 않으면 막상 만들어서 썩히지 않을까 싶어 벌려놓고 수습하기엔 요즘 한국 경제나 사업자들의 모양새는 직접 가능한한 싸게 하려고 하는것 같아 품질보다 가격이나 양이 우선시 되는 이정도면됐다 싶은 방식으로 흘러간달까"

| # | 사유 |
|---|---|
| ① | **앵커 이탈** — 대형 꼬막 양식장(잠재 앵커 거래처)이 소포장 소스를 직접 만들겠다고 결정. B2B 채널 B(꼬막 공급업체 역납품, [[위키/주제/B2B_케이스_스터디/양식장_대표님_접근_2026]]) 의 실질 소멸. |
| ② | **납품처 없이 제조 시 재고 리스크** — 국내 시장 위축. OEM만 돌리고 벌려놓으면 재고 수습 불가. |
| ③ | **시장 결 어긋남** — 시장이 품질보다 가격·양을 우선시하는 "이정도면 됐다" 방식으로 흐름. AZAE의 "접근성+품질" 방향([[위키/주제/AZAE_브랜드정신_매니페스토]])과 정합하지 않음. |

### 9.2 보류 ≠ 접음 — 열어둔 길

박준호 자기 진술:

> "정리보다는 그래서 보류에 가까워 저당소스라던지 트렌드에 맞춘 맛있는 소스 뭐 그런식으로 방향전환을 해야할지 싶지만 이 모든 사업의 토대를 나라는 브랜드를 밑에 깔고 쌓아올려야 될것같아"

- **방향 전환 후보**: 저당 소스 / 트렌드에 맞춘 소스 (재검토 대기).
- **전제**: 방향 전환도 박준호 개인 브랜드([[위키/주제/무명감자_채널]]) 가 자리를 잡은 뒤 그 위에서 재구축.
- 즉 **보류의 진짜 이유**는 시장 조건 + **순서 재정렬**(브랜드 우선 → 사업)의 결합. 상세 순서 전환은 [[위키/주제/AZAE_브랜드_사업체계]] 16절.

### 9.3 6월 톤다운 흐름의 연속

본 결정은 6월 흐름의 자연스러운 다음 걸음:

- 2026-06-29 [[위키/주제/아재꼬막_신규매장_2026]] "하나의 계획 정도" 톤다운
- 2026-06-29 [[위키/주제/멜트컴퍼니_법인_운영]] "준비 중·일단 보류"
- 2026-06-29 알파랩 "구미 당기는 투자회사 아님"
- **2026-07-29 양념장 B2B 보류**

→ 확장 라인의 무게를 순차적으로 절제하는 흐름. 재정 압박발 도피가 아니라 판단 축 성향([[위키/자아/메타인지_자기이해성향]])의 미래 자산 축을 정리하는 과정.

### 9.4 재정 압박발 지름길과의 구분 — 이것은 절제

박준호의 자기 점검 축([[위키/생각/불안과_실패의_재정의]] 5단계 분리)에서 확인:

- 이 결정은 **재정 압박에 눌려서 도망친 것이 아님** — 시장 신호와 앵커 상태를 관찰한 뒤 내린 판단.
- 오히려 "벌려놓고 수습하기" 를 피하는 절제.
- 잘못된 지름길 예: 시장이 가격 게임인데 우리도 값싼 SKU 내서 어떻게든 매출 만들기 → 결·품질 자산 훼손. 본 결정은 이 함정을 피한 것.

### 9.5 사다리 위치의 재해석

[[위키/생각/일_가치관_문제해결_자유]] 사다리에서 본 사업은 "중간 칸(양념장 B2B) → 위 칸(다층 번역 컨설팅)"으로 상승하는 다리였음(7절). 브랜드 우선 전략([[위키/주제/AZAE_브랜드_사업체계]] 16절)이 도입되면서 사다리 자체가 아래로 한 칸 확장됨:

```
[가장 위 칸] 다층 번역 컨설팅
   ↑
[중간 칸] 양념장 B2B 사업 (본 페이지, 보류)
   ↑
[중간 아래] 아재꼬막 가게
   ↑
[가장 아래 칸 · 신설] 박준호 개인 브랜드 (무명감자 채널)
```

→ 본 사업의 보류는 사다리의 "가장 아래 칸"이 먼저 자리 잡길 기다리는 것과 정합.

### 9.6 재개 신호

재개를 고려할 때 확인할 신호(제안 · 박준호 승인 시 채택):

- [[위키/주제/무명감자_채널]] 이 정서 소비를 유도할 수 있는 규모로 자리 잡음.
- 국내 시장의 품질·프리미엄 라인이 살아나거나 저당·트렌드 소스 카테고리에 명확한 수요.
- B2B 앵커 거래처 재확보(양식장 아닌 다른 채널).
- 위 세 조건 중 최소 2개.
